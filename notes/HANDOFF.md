## 현재 연구 목표 (2026-11-14 재설정)
**R–N(arXiv:2006.00516 v6) 결론 절의 열린 문제 (a): k ≥ 2에서 tight 상한 P̄(n,k,p)를 효율적으로 계산할 수 있는가?** 먼저 k = 2를 다룬다.
- 재평가와 선택 이유: `notes/reassessment_2026-11-14.md`. 1차 재평가 뒤에도 같은 흐름(사례 확장)이 반복된 원인과, 기여 판정 기준 G1–G4가 적혀 있다.
- 작업 가설 **H(k=2)**: 정렬된 주변확률을 연속인 g개 이하 묶음으로 나눈 집계 LP들의 최솟값이 P̄(n,2,p)와 같고, g는 n에 의존하지 않는다. 참이면 P̄(n,2,p)는 다항식 시간에 계산된다.
  - **g = 4판은 n = 8에서 정확한 증서로 반증되었다**(J28 e78). 그 점에서는 g = 5로 충분하다.
  - g가 유계인지는 모른다.
  - 코드: `pwbound.aggregation`. 근거: J28.
- 이전 질문("BP는 언제 정확한가", 추측 C)의 결과(`notes/proofs/exactness.md`, claims C15–C35)는 보존한다. 다만 사례 확장(C8–C13)은 더 진행하지 않는다.

## 다음 행동
1. **k = 2의 분할형 상한 구조로 R–N (a)에 답하기** (`notes/k2_structure.md`)
   - 연속 묶음 집계는 n = 8에서 정확하지 않다(C36). 원인은 최적 증서가 R 안의 비연속 클리크 분할(수 분할)을 쓰기 때문이다.
   - 명제 K1(상한, 증명됨): P̄ ≤ 2P_R − P_RP_T + e₂(p_T) + Λ_t(p_R)
   - 명제 K2(t ≥ |R|이면 숲 다면체 → 닫힌꼴, 증명됨)
   - (a) K1의 등호 영역을 증명한다. 경로: Λ_t의 쌍대 측도에서 원문제 법칙을 구성한다.
   - (b) Λ_t(p)의 복잡도를 정한다. 곱 비용 위의 Turán형 다면체다. 완전 (t−1)-분 꼭짓점이 최적인 영역을 찾으면 수 분할 또는 3-분할에서 환원하는 후보가 된다. 균등 분수점 λK_m 등 다른 꼭짓점과의 비교가 먼저다.
   - 중단 기준: Λ_t가 어떤 영역에서도 단순 닫힌꼴(균등점·별·작은 개수의 후보 최소)로 계산되면 난해성 경로를 버리고 다항식 알고리즘 쪽으로 간다.
   - 진행 상황(J30, k2_structure §5–6):
     - Λ_t는 꼭짓점이 복잡하다.
     - P̄는 수 분할 구조를 반영한다(대칭 통계로 정해지지 않는다). 다만 지배적 원소가 넷 미만일 때만 그렇다.
     - t = 4에서는 별(최댓값) 구조였다.
     - 그래서 난해성 환원은 약해졌다.
   - (A) 1차 결과(e96): 최적 증서의 역할류 수는 n = 6–10에서 2–4였다. 그 류로 집계하면 P̄와 같았다(210/210). → 가설 H′(4류 이하, 비연속 허용), k2_structure §7.
   - **다음 1순위:**
     - H′를 적대적 탐색으로 시험한다. 목표는 역할류 수를 최대화하는 p, n = 8–10이다.
     - 최적 4류 분할의 구조(정렬 순서와 어떻게 다른가, 균형 배치가 걸리는 원소는 몇 개인가)를 분류한다.
     - 구조가 "정렬 + O(1)개 원소의 배치"라면 다항식 알고리즘 정리로 간다.
   - **병행 (B):** k = 2 근사 정리 BP ≤ c·P̄. 목표 c ≈ 1.51이고, 하한 족은 이미 있다(e91). 필요한 것은 P̄의 일반 하한 구성이다.
2. k ≥ 3에서 필요한 묶음 수(e71, e76: k = 3, 4에서 n ≤ 8이면 5개). k에만 의존하는지 확인한다.
3. 따름: k = 2에서 BP/P̄의 최댓값(e66: 약 1.48). R–N의 4/3(k = 1)에 대응한다.
4. (사람) 문헌 원문: Boros–Prékopa 1989, Prékopa–Gao 2005, Qiu–Ahmed–Dey 2016(부분 집계 LP), Gabler–Schweigkoffer 1990(표본설계 존재). 이 세션에서는 arXiv만 접근할 수 있다.
5. (사람) `notes/proofs/exactness.md`의 증명 검토는 우선순위를 낮춘다. 그 결과들은 재평가에서 대부분 재적용으로 분류되었다.
