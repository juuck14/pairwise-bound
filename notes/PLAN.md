# 쌍별 독립 2+3 그룹 문제: 연구 저장소 설계와 실행 계획

## Context

KAIST ‘인공지능기반수학발견’ 개인 Math Research 과제다. 일정은 다음과 같다.
- 11/1: 데모 코드 제출
- 발표일까지: 결과 발전
- 12/10: 보고서 제출(프롬프트 요약, AI와의 상호작용 구조, 배운 점)

대상은 다음 값과 이를 달성하는 결합분포다.

M(p,q) = max P(X1+…+X5 ≥ 3), 0 ≤ p ≤ q ≤ 1

조건은 다음과 같다.
- P(X1)=P(X2)=p, P(X3..5)=q
- 10쌍 모두 쌍별 독립
- 상호 독립은 가정하지 않음

목표는 재현 가능한 저장소다. 저장소는 정확한 하한 증거(유리수 달성분포)와 상한 증거(쌍대 다항식)를 함께 만든다. 최적화 코드와 분리된 검증기가 두 값의 일치를 확인한다.

## 1. 문제 이해와 먼저 확인할 가정

### 1.1 고정할 가정 (`notes/problem.md`)
1. **쌍별 독립의 동치 조건.** 이진변수에서는 주변확률이 주어지면 Xi⊥Xj ⇔ P(Xi=1,Xj=1)=p_i·p_j이다.
   - 검증기는 중복이지만 비용이 거의 없으므로 2×2 네 칸을 모두 직접 검사한다.
2. **최댓값의 존재.** 실행 가능 집합은 공집합이 아닌 다면체다. 상호 독립 분포 Bin(2,p)×Bin(3,q)가 항상 실행 가능하므로 max가 달성된다.
3. **영역.** 경계를 포함한 0≤p≤q≤1이다. p=0, q=1, p=q 같은 퇴화 경계도 포함한다.
4. **p↔q 대칭 금지.** 탐색 결과 M(2/5,3/5)=61/75, M(3/5,2/5)=19/25로 대칭이 실제로 깨진다(재현 필요).
5. **목적 사건.** {A+B≥3}은 12상태 중 6개, 32상태 중 16개다.
6. **최대화 분포는 “하나의” 최대화 분포다.** 32상태 모형에서는 유일하지 않을 수 있다.

### 1.2 기준 모형: 32상태 LP
- 변수: μ(x)≥0 (x∈{0,1}^5)
- 등식 16개: 총합, 주변 5개, 쌍 곱조건 10개
- 목적: Σ_{|x|≥3} μ(x)

### 1.3 12상태 축소 증명 개요 (`notes/proofs/reduction.md`)
- **불변성.** G=S₂×S₃가 그룹 내부 순열로 작용한다. 다음이 모두 G-불변이다.
  - 주변 조건: 그룹 안에서 값이 같다.
  - 쌍 조건: 내부 쌍은 내부 쌍으로, 교차 쌍은 교차 쌍으로 옮겨지고 우변 p², q², pq가 같다.
  - 목적함수: |x|만의 함수다.
  - 따라서 실행 가능한 μ의 평균 μ̄=(1/12)Σ_σ μ∘σ도 실행 가능하고 목적값이 같다.
- **궤도.** S_n은 k-부분집합에 추이적이다. 그래서 궤도는 (a,b)=(|x_{G1}|,|x_{G2}|)로 정해지고 크기는 C(2,a)C(3,b)다. G-불변 분포는 π(a,b)로 결정된다.
- **모멘트 번역.** G-불변이면 다음이 성립한다.
  - E[A]=2P(X1=1)
  - E[A(A−1)]=2P(X1X2=1)
  - E[B]=3P(X3=1)
  - E[B(B−1)]=6P(X3X4=1)
  - E[AB]=6P(X1X3=1)
  - 따라서 32상태 조건과 12상태의 5개 모멘트 조건이 동치다.
- **원분포 복원(12→32).** ν(x)=π(a,b)/(C(2,a)C(3,b))로 둔다.
  - 조건부 확률은 P(Xi=1|a)=a/2, P(X1X2=1|a)=a(a−1)/2다. G2에서는 b/3, b(b−1)/6이고, 교차 쌍은 (a/2)(b/3)이다.
  - 기댓값을 취하면 p, p², q, q², pq가 되어 **10쌍 모두 독립**이다.
  - 목적값은 보존된다. π가 유리수이면 ν도 유리수다.
  - 결론: 두 LP의 최적값이 같고, 최적해는 이 사상으로 대응한다.
- **쌍대 복원.** x_i²=x_i를 쓰면 f(a,b)=y0+y1a+y2b+y3a(a−1)+y4b(b−1)+y5ab는 다음 g(x)가 된다.
  - g(x)=y0 + y1Σ_{G1}x_i + y2Σ_{G2}x_i + **2y3**·x1x2 + **2y4**·Σ_{G2쌍}x_ix_j + **y5**·Σ_{교차 6쌍}x_ix_j
  - 2배 계수는 실수하기 쉬운 함정이다.
  - 이 g를 쓰면 축소 보조정리 없이 32상태에서 상한을 직접 검증할 수 있다.

### 1.4 증거 구조
- **하한:** 유리수 32상태 분포
- **상한:** 32점에서 g(x)≥1[|x|≥3]
  - 상한 값: u0+Σu_i·p_i+Σu_ij·p_i·p_j. 12상태 기준으로는 y0+2p·y1+3q·y2+2p²·y3+6q²·y4+6pq·y5이며, (p,q)의 이차식이다.
- **최적성:** 약쌍대성에서, 두 값이 정확히(Fraction) 같으면 최적이다. 기저 정보는 신뢰하지 않는다.
- **부동소수점 LP(HiGHS)와 격자 계산:** 탐색과 교차확인에만 쓴다.

### 1.5 계획 단계 탐색 결과 (재현 필요)

- 독립 재계산: 별도 하위 에이전트가 같은 계산을 다시 해 같은 값을 얻었다.

### 2.2 신규성 구분 (잠정)
- **32상태 LP:** 기존 정식화의 재현이다.
- **대칭 축소:** 표준 기법(대칭화·집계)의 적용이다. 증명 서술은 “재현/해설”로 둔다.
- **개별 수치(61/75):** 계산 결과이며 그 자체로 신규성은 없다.
- **추가 기여 후보:** 원문이나 인용 문헌에 이미 있으면 “재현”으로 낮춘다.
  - ① 0≤p≤q≤1 전체의 정확한 조각별 이차식 공식과 정확한 영역 분류
  - ② 영역별 매개변수 달성분포의 지지집합 구조
  - ③ R–N 순서 기반 상한이 이 2+3 군에서 tight한 영역의 정확한 구분
  - ④ p↔q 비대칭의 정량화

### 2.3 “고정 쌍대해 → 유한 후보식 → 정확 분류”가 가능한 이유
1. **정리 A의 근거(정확한 증명 경로).** 정리 A는 [0,1]² 전체에서 성립하고, 연구 범위 p≤q는 그 부분집합이다. 근거는 세 가지다.
   - 쌍대 다면체가 pointed다. rank A=6이기 때문이다.
   - 모든 (p,q)에서 원문제가 실행 가능하다. 곱분포가 있기 때문이다.
   - 쌍대 꼭짓점은 924개 기저 전수열거로 **정확하고 완전하게** 얻는다.
   - 따라서 **M(p,q)=min_{y∈V} Q_y(p,q)**이고, V는 유한집합이다.
2. **영역은 쌍대 꼭짓점 단위다.** 꼭짓점 k의 영역은 R_k={(p,q): b(p,q)∈cone(k에서 tight한 열)}이다.
   - 퇴화 꼭짓점에서는 기저 하나의 임계영역 {A_B^{-1}b(p,q)≥0}이 R_k보다 작을 수 있다.
   - 쌍대 실행가능 기저들의 임계영역 합집합은 정사각형 전체를 덮는다(LP 기본정리). 그래서 덮개 성질에 격자가 필요 없다.
   - A_B^{-1}b(p,q)의 성분은 (p,q)의 2차 이하 다항식이며, 그대로 달성분포가 된다.
3. **“활성”의 정의를 고정한다.**
   - **내부 활성:** 열린 집합에서 유일 최소다.
   - **경계 활성:** M=Q_k인 점이 경계에만 있다.
   - 격자는 얇은 영역을 배제하지 못한다. 따라서 조각 목록은 목격점과 지배 증명으로 확정한다(4절).
4. **남는 난점.** 사람이 읽을 수 있는 경계 기술이다. 경계는 원뿔곡선 호와 대수적 교점으로 이루어진다.

## 3. 11/1 데모 최소 완성 범위 (MVP)
1. **정확 해법과 교차확인.** 12상태 정확 LP(기저 전수열거, Fraction)를 만든다. 32상태와 12상태 HiGHS LP를 대표점과 고정 seed 무작위 유리점에서 교차확인한다.
2. **복원과 독립 검증.** 12→32 복원(원·쌍대)을 만든다. **stdlib 단일 파일 검증기**에서 대표점 증서가 PASS하고 변조 증서가 FAIL해야 한다.
3. **한 명령 데모.** `python -m scripts.demo`를 만든다(기본 p=2/5, q=3/5; `--p --q` 옵션). LLM API 호출은 없다.
   - 출력: 최댓값(분수·소수), 12상태 분포, 32상태 분포(0이 아닌 항), 상한 증서(f, 32상태 계수, 이차식 값), 검증기를 하위 프로세스로 실행한 항목별 PASS/FAIL
   - 저장: `results/certificates/*.json`
4. **일관성 테스트.**
   - 곱분포가 실행 가능한지
   - p=q 표본점에서 단변수 S 모형과 일치하는지
   - p≠q 비대칭 예
   - 경계점 p=0, q=1
   - 상식 범위: 곱분포 값 ≤ M ≤ min(1,(2p+3q)/3)
5. **문서.** 축소 증명, 문헌 표(확인 수준 포함), claims 상태표, 연구일지, AI 상호작용 기록, HANDOFF.
6. **(선택)** 쌍대 꼭짓점 V를 출력하고, 임의 유리점에서 min Q_y가 정확 LP 값과 같음을 확인한다. 정리 A의 계산 증거가 된다.

## 4. 이후 확장 연구 목표 (11/1 이후 ~ 발표 ~ 12/10)
1. **정리 A(유한 포락선):** M=min_{y∈V} Q_y.
   - 증명 문서를 쓴다.
   - 검증기가 924개 기저를 자체 코드로 다시 열거해 V를 대조한다.
2. **정리 B(조각과 달성분포):**
   - 내부 활성 조각마다 증서를 둔다: 유리수 목격점, 그 점에서 x_B>0 (strict)인 기저, 쌍대 실행가능 y.
   - 그 점에서 쌍대 최적해가 유일하므로, 근방에서 Q_k가 strict 최소다.
   - 조각마다 항등식을 검사한다. A·x_B(p,q)≡b(p,q)이고, x_B의 지지집합이 tight 집합에 포함되어야 한다.
3. **비활성 증명:**
   - 삼각형을 재귀적으로 분할한다. 각 잎 삼각형에서 Q_j−Q_k≥0을 정확히 보인다.
   - 이차식의 삼각형 위 최솟값은 정확히 계산된다. 정류점, 변 위의 1변수 이차식, 꼭짓점만 보면 된다.
   - 해결되지 않는 잎은 기록하고 sympy 분해로 처리한다.
4. **경계 기술:**
   - 경계는 Q_k=Q_l 원뿔곡선과 x_B 성분 0 곡선 위에 있다. 교점은 종결식과 실근 분리로 구한다.
   - 두 영역 기술(min-of-quadratics와 cone membership)의 일치를 테스트한다.
   - matplotlib로 영역도를 그린다.
5. **문헌 대조:**
   - p=q 단면을 Boros–Prékopa/R–N 동일 주변확률 정리와 대조한다(재현).
   - R–N 순서 기반 상한을 정확값과 비교해 tight 영역을 구분한다.
6. **(여유가 있으면) 확장:**
   - p>q 쪽을 포함한 [0,1]² 전체 분류와 비대칭 정량화
   - 그룹 크기와 k를 바꾼 계산 실험. 신규 주장 없이 관찰로만 기록한다.
7. **보고서:** 프롬프트 요약, 상호작용 구조(사람 판단, AI 제안, 검증기의 역할), 실패 기록, 배운 점.

**범위 축소 순서.** 전체 분류가 정체되면 다음 순서로 좁힌다.
- ① p=q 단면(완전 재현)
- ② 대표점을 포함하는 단일 조각의 공식, 달성분포, 경계
- ③ 고정 q 단면(예: q=3/5)에서 p의 1변수 조각함수
- ④ 작은 p 근방 영역

### 의존성과 이유
- **numpy:** 이미 설치되어 있다. scipy 입력에 쓴다.
- **scipy:** HiGHS. 정확 코드와 공유하지 않는 유일한 독립 해법이다.
- **pytest:** 테스트.
- **sympy:** MVP 이후. 종결식과 실근 분리에만 쓰고, 검증기에는 쓰지 않는다.
- **matplotlib:** MVP 이후. 영역도.
- **추가하지 않는 것:** cvxpy, pulp 등. 문제 규모상 불필요하다.

### 검증기 독립성 장치
- verify.py는 `pwbound`를 import하지 않는다.
  - `test_independence.py`가 AST로 import 허용목록을 검사한다.
  - float 리터럴, `float(`, `eval`, `exec`, `__import__`도 금지한다.
- 실행은 임시 디렉터리에서 `python -I verifier/verify.py cert.json`으로 한다.
- 영역 모드의 다항식 항등식은 차수 ≤2이므로, stdlib의 단항식 dict 연산으로 검사한다.

### 증서 형식 `pw5-point/v1`
- **숫자:** 모든 숫자는 `^-?\d+(/[1-9]\d*)?$` 문자열이다.
- **JSON 로딩:** `parse_float`이 오류를 내게 한다. 중복 키도 거부한다.
- **상태 키:** `"x1x2x3x4x5"` 비트열이며, 왼쪽이 X1이다.
- **필드:**
  - `problem{p,q,groups,threshold}`
  - `claim.value`
  - `primal.reduced` / `primal.lifted`(32개 전부)
  - `dual.reduced{y0..y5}` / `dual.lifted{const,x,xx}`
  - `provenance`
- **검사 내용:** 검증기는 p, q에서 모든 제약을 다시 만들어 다음을 검사한다. provenance와 기저는 신뢰하지 않는다.
  - 0≤p≤q≤1
  - 비음수, 총합, 주변 5개, 쌍 10개(네 칸)
  - 목적값=claim
  - 32점 지배
  - 쌍대값=원값

## 7. 수학적 오류 가능성과 검증 방법

| 위험 | 대응 |
|---|---|
| 축소 계수 오류(2p², 6q², 6pq) | 곱분포 실행가능성 테스트, HiGHS 32상태 비교, 32상태 검증기 |
| 쌍대 복원 2배 계수 오류 | 32점 검증과, 2배를 빠뜨린 변조 증서의 FAIL 테스트 |
| 비트 순서·그룹 혼동 | p≠q 테스트. 검증기는 명세에서 제약을 재구성하고, 비트 반전 증서는 FAIL해야 한다 |
| 부동소수점 오염(`Fraction(0.4)`) | 엄격한 문자열 파싱, AST의 float 금지, "0.4"·"1e-3"·"nan" 거부 테스트 |
| 열거 누락·중복 제거 오류 | rank 테스트, 검증기의 독립 재열거, 무작위 점 HiGHS 비교 |
| “min over V”의 전제 누락 | 증명 문서와 테스트에 pointedness와 실행가능성을 명시 |
| 격자 기반 영역 주장 | 목격점과 분할 지배 증명으로만 확정. 격자 결과는 “탐색” 표기 |
| 퇴화·동률(p=0, q=1, 다중 기저 꼭짓점) | 검증기는 기저를 무시하고 비엄격 활성 정의를 쓴다. 경계 전용 테스트를 둔다 |
| 해법과 검증기가 같은 실수를 공유 | SPEC 선작성, 사람 검토, HiGHS(코드 비공유) |
| 검증기 자체 버그 | 음성 테스트를 둔다. 각 테스트는 특정 실패 코드를 기대한다. 대상: 주변 깨기, 쌍 깨기, 커널 이동으로 음수 만들기, 목적 감소, y0 증감, 2배 오류, 값 1/10⁹ 차이, 키 누락·추가·중복, p>q |
| 문헌 오독(판본별 번호 차이) | 판본, 쪽, 정리 번호와 짧은 인용 구절을 기록 |
| AI의 그럴듯한 주장 | 근거 없이는 claims에서 “추측” 유지. 검증기 독립성은 테스트로 강제 |

## 가장 먼저 구현할 작은 작업

**검증기 우선: 대표점 증서 하나를 독립 검증한다.**
1. `verifier/SPEC.md`에 검사 항목, 입력 형식, 실패 코드를 적는다. 사용자 검토를 받는다.
2. `verifier/verify.py`(stdlib 전용, point 모드)를 SPEC만 보고 작성한다.
3. `src/pwbound/model.py`에 12·32상태 정의, 원분포 복원(π/(C(2,a)C(3,b))), 쌍대 복원(2y3, 2y4, y5)을 둔다.
4. 계획 단계 탐색의 π와 f로 `results/certificates/p2_5-q3_5.json`을 만든다.
5. 테스트를 둔다.
   - (i) 곱분포 실행가능성
   - (ii) 대표점 증서 PASS, 값 61/75
