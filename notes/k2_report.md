## 요약

- **질문.** R–N(Ramachandra–Natarajan, SIAM J. Discrete Math. 2023)은 결론에서 열린 문제 (a)를 남겼다. "k ≥ 2에서 tight 상한 P̄(n,k,p) = max P(X₁+…+X_n ≥ k)(쌍별 독립, 주변확률 p)를 효율적으로 계산하거나 근사할 수 있는가?" 이 문서는 k = 2를 다룬다.
- **답의 현황.** 정확 계산의 복잡도는 **미해결**이다.
- **이번에 확정한 것.**
  - 자연스러운 다항식 크기 축약인 "묶음 집계"는 정확하지 않다. 연속 묶음 4개(C36)도, 임의 류 4개(C37)도 아니다. 필요한 류의 수는 n과 함께 자란다.
  - P̄의 최적 증서는 작은 좌표들 사이의 **조합적 선택**을 담는다. 균형·가중 분할, 중첩 매칭이 그 예다.
  - 양의 결과로는 다음이 있다.
    - 모든 p에서 성립하는 상한 족(명제 K1)
    - 특수한 경우의 닫힌꼴(명제 K2, 숲 다면체)
    - O(n²) 시간의 상수배 근사(명제 A2, 작은 결과)
    - BP 상한이 P̄보다 1.505배 이상 클 수 있다는 정확한 예
- **기여로 내세울 수 있는 정도.** 열린 문제에 대한 **부분적·부정적 진전**이다. 정리급 결과(알고리즘 또는 난해성)는 아직 없다. §4에 정직한 판정을 적었다.

## 0. 2026-11-15 추가: 다항식 알고리즘 후보 (가설 R3′) — **이후 반증됨(아래 0.1)**

정리 이후 "끝까지 파라"는 지시로 이어 간 결과다(k2_structure §13).
- **관찰.** 최적 법칙은 원자(확률이 실린 0/1 벡터)가 많아야 1 + n + C(n,2)개면 된다(LP 기저해). 문제는 어떤 원자인가다.
- **가설 R3′(k = 2).** P̄ < 1이면, 정렬 순서에서 1-좌표가 **3개 이하의 구간(run)**을 이루는 원자만 쓰는 LP의 값이 P̄와 같다.
  - 세분 R3″: 최댓값을 포함한 접미 구간을 떼면 ≤ 2구간이다.
- **근거.**
  - 무작위·적대적 시험: n = 8–18, 수백 점에서 차이 ≤ 10⁻¹⁴ 수준이었다(n = 12의 한 점만 6·10⁻⁸, 풀이기 허용오차 수준).
  - C36·C37 점을 포함한 어려운 세 점에서는 유리수 정확 검증으로 3구간 법칙의 값 = 정확한 쌍대 상한을 확인했다.
  - 2구간으로는 부족하다(최대 2·10⁻⁴).
- **"3"의 이유(증명됨, 간단).**
  - P̄ < 1이면 정리 C4에 의해 S₁ < 3이다.
  - r-구간 법칙은 Σᵢ P(xᵢ ≠ xᵢ₊₁) ≤ 2r을 요구하는데, 이 합은 ≤ 2S₁ < 6이다.
  - P̄ = 1인 점(S₁이 큼)에서는 3구간 원자로 모멘트를 맞출 수조차 없다(n = 18 예). 그러나 그 경우는 정리 C4가 판정한다.
- **R3′가 참이면 알고리즘.**
  1. LOO_j ≥ 2(모든 p_j < 1)이면 P̄ = 1이다.
  2. 아니면 원자 O(n⁶)개(R3″이면 O(n⁵)개), 제약 O(n²)개인 LP를 푼다(`pwbound.runs_lp`).
  - 이것은 R–N 열린 문제 (a)의 k = 2에 대한 **다항식 시간 답**이 된다.
- **상태.** 증명이 없으므로 **추측**이다. 이 절은 아래 §2–§5의 "정확 계산 미해결" 판단을 "다항식 시간일 강한 근거가 있으나 증명 없음"으로 바꾼다.

## 0.1 R3′ 반증 (2026-11-15)
- n = 13, p = (0.0219×6, 0.0259, 0.0278, 0.0288, 0.0398, 0.3486, 0.3688, 0.4033)(P̄ < 1)에서 3구간 LP가 전체 LP보다 7.8·10⁻⁴ 작다. 4구간이면 같다(k2_structure §15).

- 따라서 "3구간이면 충분"은 거짓이다. 필요한 구간 수가 유계인지는 미해결이다.
- 위 §0의 "다항식 시간일 강한 근거"는 철회한다. 무작위 표본에 구조적 유형이 빠져 있었다.

## 0.2 새 다항식 알고리즘 후보: 구간 설계 LP (가설 S3a, 2026-11-15)
- **열.** 정렬 순서에서 서로소인 구간 ≤ 3개를 둔다. 그중 많아야 하나에서는 c개를 균등 추출하고, 나머지 구간은 전부 포함한다. 열 수는 O(n⁷)다. 각 열의 모멘트는 닫힌꼴이고 크기는 결정적이다(`pwbound.segment_lp`).
- **가설 S3a.** P̄ < 1이면 이 LP의 값이 P̄와 같다.
- **근거.**
  - R3′ 반례(n = 13)에서 유리수로 정확히 P̄를 달성한다(C38).
  - 거의 같은 값, 같은 값 묶음 1–2개, 다중 척도 사례, 적대적 탐색에서 모두 일치했다(차이 ≤ 10⁻⁷, 엄격한 재풀이에서 10⁻¹² 이하).
  - n = 17에서는 구간 LP의 정체값과 같았다.
- **알고리즘(가설이 참이면).**
  1. 정리 C4로 P̄ = 1인지 판정한다.
  2. 아니면 S3a LP를 푼다. → R–N (a)의 k = 2에 대한 다항식 시간 답이 된다.
- **상태.** 추측이다. 증명이 없다.

## 1. 질문과 출처 (G3, G4)

- **출처.** R–N v6 LaTeX 원문의 결론 절 (a)다. 원문을 직접 확인했다. R–N은 다음을 알려 두었다.
  - k = 1: 닫힌꼴(Kounias–Hunter–Worsley, KHW). 최댓값 좌표를 중심으로 한 "별"이다.
  - 동일 주변확률: Boros–Prékopa(BP) 닫힌꼴
  - k ≥ 2이고 주변확률이 서로 다른 경우: tight하지 않은 순서 기반 상한만 있다.
- **문헌 확인 범위(2026-11-14).**
  - R–N을 인용한 8편(Semantic Scholar 인용 목록): k ≥ 2이고 주변확률이 서로 다른 경우의 계산을 다룬 것은 없었다.
  - 집계 LP 계열:
    - Prékopa–Gao 2005: 출판사 자동 접근 차단으로 서지만 확인했다.
    - Boros–Lee arXiv:2110.10672: 초록만 확인했다.
    - 둘 다 임의의 쌍 확률을 다룬다.
  - 신규성은 이 범위 안에서만 판단했다.
- **표기.**
  - S = Σ X_i, S₁ = Σ p_i, S₂ = Σ_{i<j} p_ip_j.
  - LP 쌍대로 P̄ = min{E q : q는 이차식이고 모든 x ∈ {0,1}ⁿ에서 q(x) ≥ 1{|x| ≥ 2}}이다. 여기서 E q는 곱 모멘트로 계산한다. 이런 q를 **증서**라 부른다.

### 2.1 반례 C36·C37이 말하는 것
- **집계 LP.** 좌표를 류(class)로 묶고 류별 개수의 법칙만 남긴 LP다. 모든 분할에서 P̄의 상한이고, 홑원소 분할이면 P̄ 자체다.
- **k = 1.** "최댓값 하나 + 나머지" 2류 집계가 정확하다. KHW의 재해석이다(`::test_k1_two_contiguous_groups_reproduce_khw`).
- **동일 주변확률.** 1류 집계(BP)가 정확하다.
- **k = 2.** 그런 고정 개수 축약이 없다.
  - n ≤ 7의 모든 시험점에서는 연속 4묶음이 정확했다.
  - n = 8에서 깨진다(C36). 최적 증서가 작은 좌표들을 p-합이 균형 잡힌 두 클리크 {1,3,4} | {2,5}로 나누기 때문이다.
  - n = 9에서는 임의 4류도 깨진다(C37). 최적 증서의 류가 {1,4}, {2,3}, {5,6}, {7}, {8,9}로 5개다.
- **의미.** "소수의 묶음으로 집계하면 정확하다"는 형태의 다항식 알고리즘은 성립하지 않는다.

### 2.2 분할형 상한 K1과 닫힌꼴 K2
- **덮개 LP.** Λ_t(p_R) = min{Σ w_ij p_ip_j : 모든 S ⊆ R에서 w(E(S)) ≥ f_t(|S|)}. f_t(s)는 다음과 같다.
  - s ≤ t일 때: C(s−1,2)
  - s ≥ t일 때: (t−2)s − C(t,2) + 1
- **K1.** 위 덮개 LP를 쓴 상한이다. 증서 q = 2N_R − N_RN_T + C(N_T,2) + Σ w_ij x_ix_j의 유효성 조건이 바로 그 덮개 제약이다.
- **K2.** t ≥ |R|이면 x = 1 − w로 바꿔 숲 다면체(Edmonds) 위의 최대 가중 숲이 된다. 곱 가중치에서는 최댓값을 중심으로 한 별이 최적이다. 이 구조는 k = 1의 KHW 별과 같다.
- **K1이 P̄와 같아지는 영역.** 작은 R + 적당한 T 영역에서는 탐색상 대부분 같았다. 다만 K2의 닫힌꼴 그대로 tight한 영역은 좁았다(§3, e93).

### 2.3 근사: A2와 R1
- **A2.** 독립 법칙은 쌍별 독립이고, Markov 부등식으로 P̄ ≤ min(1, S₂)이다. 독립 합에 Paley–Zygmund와 Newton–Maclaurin을 쓰면 P_ind(S≥2) ≥ min(1,S₂)/(2+2√2)이다. 그래서 O(n²) 동적계획으로 계산되는 P_ind(S≥2)가 4.83배 근사가 된다. 수치상 최악은 ≈ 2.42(Poisson 극한)이다.
- **R1.** 한 좌표가 1이면 P̄는 나머지에 대한 KHW로 정확히 계산된다. 이를 써서 BP가 1.505배 이상 과대일 수 있음을 정확히 보였다. k = 1의 4/3(R–N Prop. 2.5)에 대응하는 하한 쪽 사례다.
- **k ≥ 3.** 같은 논법이 성립하지 않는다. 쌍별 독립의 P̄는 S₂ 크기이고, 독립 법칙은 e_k 크기라서 비가 유계가 아니다.

- 구조 증거(O1, O2)

1차 재평가가 경계한 "사례 계산"과는 다르다. 질문의 출처가 원 논문의 열린 문제이고, 결과가 일반 접근법의 성립 여부를 가른다. 다만 독립된 성과로 내세우기에는 작다.

## 5. 열린 문제

1. **P̄(n,2,p)의 정확 계산은 다항식 시간인가?**
   - 증거는 엇갈린다.
     - 구조(필요한 류의 수)는 n과 함께 자란다.
     - 그러나 조합 선택(분할, 매칭)은 대부분 정렬과 재배열로 정해지고, 비슷한 크기의 원소는 LP가 평활화한다.
   - 결정적인 다음 단계는 둘 중 하나다.
     - (a) 덮개 LP Λ_f(곱 비용, 제약이 |S|에만 의존)를 다항식 시간에 푸는 방법
     - (b) Λ_f 또는 P̄를 이용한 난해성 환원
2. **근사.**
   - k = 2: 최선 상수(예상 ≈ 2.42, A2의 독립 법칙)와 BP의 최악 비(≥ 1.505, 예상 ≈ 1.507)를 정확히 결정한다.
   - 고정된 k ≥ 3: 다항식 시간 상수배 근사가 있는가? 수치상 구성적 하한은 3배 안쪽이었다(e109). 증명은 없다.
3. **K1의 등호 영역 증명.** 원문제 법칙의 구성이 필요하다.
