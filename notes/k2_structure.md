## 1. 연속 묶음 집계는 정확하지 않다 (정확 계산 검증, claims C36)
- n = 8 반례가 있다(`tests/test_aggregation.py::test_k2_four_groups_fail_at_n8_exact`).
- 그 점의 최적 쌍대 증서(반정수)는 다음과 같다.

  q = 2N_R − N_R N_T + C(N_T, 2) + (x₁x₃ + x₁x₄ + x₃x₄) + x₂x₅

  여기서 R = {1,…,5}(작은 좌표), T = {6,7,8}(큰 좌표)이다. R 안의 이차항은 클리크 두 개 {1,3,4}, {2,5}다.
- 이 분할은 연속이 아니다. 두 클리크의 p-합(0.0713, 0.0755)을 가장 균형 있게 만드는 분할이다.

## 2. 분할형 상한 (증명됨: 유효성)
좌표를 R과 T로 나누고 t = |T|라 하자. f_t(s)는 다음과 같다.

f_t(s) := max_{0≤j≤t} [ 1{s+j ≥ 2} − (2−j)s − C(j,2) ]

s ≥ 2이면 이 값은 다음과 같다.
- s ≤ t일 때: C(s−1, 2)
- s ≥ t일 때: (t−2)s − C(t,2) + 1

**명제 K1.** 다음을 정의한다.

Λ_t(p_R) := min { Σ_{i<j∈R} w_ij p_ip_j : w(E(S)) ≥ f_t(|S|) for all S ⊆ R }

그러면 모든 p에 대해 다음이 성립한다.

P̄(n,2,p) ≤ 2P_R − P_R P_T + e₂(p_T) + Λ_t(p_R)

*증명.* q(x) = 2N_R − N_R N_T + C(N_T,2) + Σ_{i<j∈R} w_ij x_ix_j로 둔다.
- 유효성: x_R의 지지가 S(|S| = s)이고 N_T = j이면 q = 2s − js + C(j,2) + w(E(S))이다. 따라서 "q ≥ 1{|x| ≥ 2}가 모든 x에서 성립"은 "w(E(S)) ≥ f_t(|S|)가 모든 S에서 성립"과 같다.
- 쌍별 독립 기댓값은 E q = 2P_R − P_R P_T + e₂(p_T) + Σ w_ij p_ip_j이다.
- LP 쌍대로 P̄ ≤ E q이다. ∎

**명제 K2 (t ≥ |R|이면 닫힌꼴, 증명됨).** t ≥ |R| = m이면 다음이 성립한다.

Λ_t(p_R) = e₂(p_R) − p_max (P_R − p_max)

*증명.*
- 이때 모든 S에서 제약은 w(E(S)) ≥ C(|S|−1, 2)이다.
- x = 1 − w로 바꾸면 이 제약은 x(E(S)) ≤ |S| − 1이 된다(|S| = 2에서 x ≤ 1).
- 목적함수는 e₂(p_R) − Σ x_ij p_ip_j이다. 비용이 음이 아니므로 x ≥ 0을 더해도 최적값은 같다. 따라서 숲 다면체(Edmonds) 위에서 가중치 p_ip_j의 최대 숲을 찾는 문제가 된다.
- 곱 가중치에서는 최댓값 좌표를 중심으로 한 별이 최대 생성나무다. 아무 나무나 최댓값 꼭짓점에서 뿌리를 내려 보면, 각 비뿌리 꼭짓점 i의 부모 변 가중치는 p_i p_parent ≤ p_i p_max이다. ∎

(구조가 R–N Theorem 2.3의 KHW 별과 같다. k = 1의 "최대 생성나무"가 k = 2에서도 R 안에서 나타난다.)

## 3. t < |R|: Turán형 제약 (탐색)
- s > t인 집합에서는 제약이 선형 (t−2)s − C(t,2) + 1로 약해진다.
- x = 1 − w로 보면 다음과 같다.
  - s ≤ t인 집합: 숲 조건이다. 길이 ≤ t인 순환이 금지된다.
  - s > t인 집합: x(E(S)) ≤ C(s,2) − (t−2)s + C(t,2) − 1이다.
- t = 3이면 x의 0/1 점은 다음과 같다.
  - 삼각형이 없다.
  - 4-집합 안의 변은 많아야 4개다.
  - 예: 완전 이분 그래프 K_{A,B}
  - 그 가중치 P_A P_B를 최대화하는 것은 수 분할(number partitioning) 문제다.
- 다면체는 정수가 아니다. x = (2/3)·1(곧 w = (1/3)K_m)이 꼭짓점이고, 많은 점에서 최적이다(e85).
  - 0/1 완전 이분 쪽이 이길 조건(t = 3, 균등 비교): P_R² + 3d² < 4Σ p_i². 여기서 d는 두 쪽 합의 차다.
- **탐색(e86–e87):** "작은 R + 크기가 적당한 T" 영역에서는 명제 K1의 상한이 P̄와 같았다.
  - t = 3: 120점 중 105점
  - t = 4: 30점 중 24점
  - t = 6: 12점 중 10점
  - 나머지 점에서는 다른 바깥 구조의 증서가 더 작다.

## 4. 열린 질문 (다음 단계)
1. **K1의 등호 영역 증명.** 영역(R 작음, T 적당)에서 P̄가 2P_R − P_RP_T + e₂(p_T) + Λ_t(p_R)와 같음을 보인다. Λ_t의 LP 쌍대(Σ_{S ⊇ {i,j}} y_S ≤ p_ip_j인 부분집합 위의 측도)로 원래 LP의 원문제 법칙을 만드는 것이 자연스러운 경로다.
2. **Λ_t(p)의 복잡도.** 곱 비용 위에서 이 Turán형 다면체를 최적화하는 문제다.
   - 0/1 꼭짓점 중 완전 (t−1)-분 그래프가 최적이 되는 영역이 있으면 수 분할(t−1 = 2) 또는 3-분할(t ~ m/3)이 들어와 NP-난해성 후보가 된다.
   - 균등 분수점(λK_m)이 늘 이기거나 구조가 단순하면 다항식 시간 후보가 된다.
   - 대략 비교: t ~ m/3이면 완전 분할의 값은 ≈ P²/m, 균등 분수점은 ≈ P²/2라서 분할 쪽이 훨씬 작다. 다른 분수 꼭짓점과의 비교는 아직 하지 않았다.
3. 1과 2가 되면 R–N (a)의 k = 2에 대한 답(난해성 또는 알고리즘)이 된다.

## 6. 다음 선택지 (판단 기준 G1–G4로)
- (A) **정확 계산의 복잡도.**
  - 가설: "지배적 원소 소수 + 나머지 집계"로 다항식 시간에 계산된다.
  - 시험: 무작위·적대적 점에서 최적 쌍대 증서의 "비대칭 원소 수"가 n과 함께 자라는지 본다.
  - 자라지 않으면 그 구조를 증명한다. 자라면 그 구조에서 난해성 환원을 찾는다.
- (B) **근사 정리.**
  - k = 2에서 BP ≤ c·P̄를 증명한다. 목표 c ≈ 1.51이고, 하한 족은 위에 있다.
  - 필요한 것은 P̄의 일반 하한 구성이다(조건화 + 솎아내기 + 동일 주변확률 구성의 조합).
  - k ≥ 3은 BP 대신 R–N 순서 기반 BP나 다른 계산 가능한 상한이 필요하다.

## 7. 역할류 가설 H′ (탐색, e96)
- 최적 쌍대 증서(HiGHS 꼭짓점)에서 "역할류"를 정의한다. 좌표 i, j를 맞바꿔도 q가 변하지 않으면 같은 류다.
- 역할류의 수는 다음과 같았다(P̄ < 1인 무작위 점, 각 n에서 80/60/40/20/10개).
  - n = 6: 1–4
  - n = 7: 1–4
  - n = 8: 2–3
  - n = 9: 2–3
  - n = 10: 2–3
- 역할류(연속이 아닐 수 있음)로 집계한 LP는 210점 모두에서 P̄와 같았다.
- **가설 H′(k=2):** 많아야 4개 역할류를 갖는 최적 증서가 늘 있다.
  - 그러면 P̄(n,2,p) = min over 4개 이하 류로의 분할(연속일 필요 없음) of 집계 LP다.
  - 연속 제한판(H)은 거짓이다(C36). 그 반례의 역할류는 {1,3,4}, {2,5}, {6,7,8}로 비연속이다.
- 의미: 계산은 "최선의 4류 분할 찾기"라는 조합 최적화가 된다.
  - 다항식 알고리즘이 되려면 최적 분할이 구조적이어야 한다. 예: 정렬 순서 + 소수 지배 원소의 균형 배치.
  - 난해성이 되려면 많은 원소의 균형 분할이 강제되는 영역이 있어야 한다. §5에 따르면 2분할은 지배 원소가 넷 미만일 때만 강제된다.
- 적대적 시험(e97–e98):
  - n = 7, 8에서 HiGHS 쌍대의 역할류 수를 최대화했다(16회). 최대 6류였다(n = 8).
  - 그 점(p = (0, 0.0255, 0.0248, 0.0837, 0.1222, 0.2744, 0.5642, 0.3169))에서 4류 이하 집합분할 2,795개를 전수 조사했다.
  - 최솟값이 P̄와 정확히 같았다. 유리수 계산으로, 쌍대 상한 0.63832791 = 분할별 정확 실행 가능 값의 최솟값이다.
  - 즉 쌍대 꼭짓점이 비대칭이어도, 4류 대칭인 다른 최적 증서가 있다. H′는 아직 반례가 없다.
- 최적 분할의 구조(e99): n = 8 반례에서 P̄를 달성하는 4류 이하 분할은 8개였다. 모두 R = {1..5}의 균형 2분할 {1,3,4} | {2,5}(합 0.0713 대 0.0755)를 존중한다. 그 두 쪽을 한 류로 섞지 않는다. T = {6,7,8}은 자유롭게 쪼개진다.

## 8. 난해성 환원 시도와 실패 이유 (논증, 2026-11-14)
- 시도: R = {2b, b, b} ∪ {ε·a_i}(a_i는 PARTITION 사례, εΣa ≲ 0.9b), T = 3개, t = 3 영역.
  - 큰 원소는 {2b} | {b,b}로 갈리고, 작은 원소의 배치가 불균형 d를 정한다.
  - 2-클리크 꼭짓점의 값은 상수 + d²/4다.
- 실패 이유: LP Λ_3에는 다음 분수해가 있다.
  - 각 작은 원소 i에 w(i, 큰 원소) = 1/2를 준다.
  - 이때 1차 비용(2b·εa_i)이 정수 배치와 같다.
  - 작은 원소끼리는 삼중 제약 때문에 평균 1/3 이상의 가중치가 강제되고, 균등 1/3이면 실행 가능하다.
  - 2차 비용을 비교하면 균등 1/3(≈ Σ²/6)이 정수 분할(≈ Σ²/4 + D²/4)보다 작다. 작은 원소가 많을수록 그렇다.
  - 따라서 분할 민감성이 사라진다.
- 결론: 수 분할 민감성은 지배적 원소가 소수일 때만 나타난다. 이는 (A) "소수 지배 원소의 배치 열거 + 나머지 집계"형 다항식 알고리즘 가설을 지지한다. 증명은 없다.

## 10. 명제 A2 (k = 2의 상수배 근사, 증명됨; 작은 결과)
**명제 A2.** 모든 n, p에 대해 다음이 성립한다.

P_ind(S ≥ 2) ≤ P̄(n,2,p) ≤ BP(S₁,S₂) ≤ min(1, S₂) ≤ (2 + 2√2)·P_ind(S ≥ 2)

여기서 P_ind는 독립 법칙에서의 확률이다. 따라서 O(n²) 동적계획으로 계산되는 P_ind(S≥2)는 P̄(n,2,p)의 (2+2√2 ≈ 4.83)-근사다. BP도 같은 비율 안에 있다.

*증명.*
- 첫째 부등식: 독립 법칙은 쌍별 독립이다.
- 셋째 부등식: Markov 부등식 P(S≥2) ≤ E C(S,2) = S₂와 1이다.
- 넷째 부등식: Y = C(S,2)로 둔다. 독립 법칙에서 E Y = e₂이고, E Y² = e₂ + 6e₃ + 6e₄이다(C(S,2)²을 세면 공통 원소 1개인 순서쌍 6, 서로소인 순서쌍 6이 나온다).
  - Paley–Zygmund(Cauchy–Schwarz)로 P(Y > 0) ≥ e₂²/(e₂ + 6e₃ + 6e₄)이다.
  - Newton–Maclaurin 부등식에서 (e_j/C(n,j))^{1/j}는 j에 대해 비증가한다. 따라서 6e₃ ≤ 2√2·e₂^{3/2}, 6e₄ ≤ e₂²이다.
  - 그러므로 P(S≥2) ≥ e₂/(1 + 2√2√e₂ + e₂)이다. 이는 e₂ ≤ 1이면 e₂/(2+2√2) 이상이고, e₂ ≥ 1이면 (증가함수이므로) 1/(2+2√2) 이상이다. ∎

- 수치(e107, e111): inf P_ind/min(1,S₂)는 무작위 20만 점에서 0.481, Poisson 극한(λ = √2)에서 0.413이다. 그래서 상수 2+2√2는 날카롭지 않다(예상 최선은 ≈ 2.42). 실측 P̄/P_ind ≤ 1.52이고, BP/P̄ ≥ 1.5055인 족이 있다(e91).
- **기여 판정(G1–G4):**
  - G1: 모든 n.
  - G2: 새 단계는 고전적 도구(Paley–Zygmund, Maclaurin)의 짧은 조합이다. 작다.
  - G3: R–N 결론 (a)의 "근사" 부분에 k = 2로 답한다.
  - G4: 이 꼴의 부등식이 문헌에 있는지는 미확인이다.
  - **작은 관찰로 분류한다.**
- k ≥ 3에서는 같은 논법이 성립하지 않는다. 쌍별 독립은 P(S≥k)를 S₂/C(k,2) 크기까지 올릴 수 있는데, 독립 법칙은 e_k 크기이기 때문이다.

## 11. 지지 제한과 구간 수(run) 가설 (2026-11-15, e112–e113)
- **지지 제한(e112):** 원문제 법칙의 지지를 "크기 ≤ s이거나 ≥ n − s′인 집합"으로 제한하는 다항식 크기 LP를 시험했다. (s, s′) = (2,0), (3,0), (3,1), (3,2)는 n ≥ 7에서 모멘트 자체가 실행 불가였다. (4,2)도 n = 8, 9에서 P̄보다 0.018–0.025 작았다. → 중간 크기 집합이 필요하다. 이 경로는 닫혔다.
- **구간 수 가설(시험 중, e113):** 4류 이하이면서 정렬 순서의 구간(run) 수가 R 이하인 분할만으로 P̄를 얻는다. 참이면 후보 분할이 O(n^{R−1}·4^R)개라 다항식 알고리즘이 된다. n = 9 반례의 유일한 4류 최적 분할은 A B AAA B C DD로, 구간 6개다.
- **원문제·쌍대의 조합적 형태(정리, 표준 LP 쌍대):**
  - μ(0) + Σ_i μ(e_i)를 최소화하는 것은, 크기 ≥ 2인 집합 위의 측도 ν의 총질량을 최대화하는 것과 같다. 제약은 다음 셋이다.
    - 쌍 덮개가 정확히 p_ip_j
    - 꼭짓점 사용량 ≤ p_i
    - 총질량 ≤ 1
  - 쌍대는 min Σ y_ij p_ip_j + Σ z_i p_i + w이고, 제약은 다음과 같다.
    - z ≥ 0, w ≥ 0, y의 부호는 자유
    - |x| ≥ 2인 모든 x에서 y(E(x)) + z(x) + w ≥ 1
  - 관찰된 최적 증서는 모두 w = 0이었다(P̄ < 1일 때).
  - 해석: 꼭짓점 가중치 z와 변 가중치 y(음수 허용)로 크기 2 이상인 모든 집합을 가중치 1 이상으로 덮는 최소 비용 문제다. 비용은 곱 꼴이다.
- **e113 결과:** 연속 4-묶음이 실패한 9개 점 모두에서, 4류 이하 최적 분할의 최소 구간 수는 5–6이었다.
  - 공통 구조: R(작은 좌표 묶음)이 **"한 쌍 {a,b}" 대 "나머지"**로 갈린다. 관찰된 쌍은 {2,5}, {2,6}, {3,6}이다.
  - 쌍은 늘 R의 최댓값 + 균형용 원소 하나였다.
  - 증서 쪽에서 보면 (1/3)K_나머지 + (2/3)K_쌍이다. 쌍 선택은 P_쌍(P_R − P_쌍) − ab를 최대화하는 O(n²) 문제다.
- **가설 H5:** P̄(n,2,p) = min over {연속 ≤4 묶음 분할} ∪ {그중 한 묶음에서 쌍 하나를 따로 뗀 분할(총 ≤ 4류)}. 후보는 O(n³·n²)개이므로, 참이면 다항식 시간이다. 시험 중(e114).

## 12. H5 시험, H′의 반증, 안쪽 문제의 "결함 허용 덮개" 구조 (2026-11-15, e114–e119)
- **H5(연속 + 한 묶음에서 쌍 하나 분리)(e114):**
  - n = 8에서 연속 실패 16점 중 15점을 고쳤다. 남은 1점은 반올림한 점에서 차이가 0이었다(수치 허용오차).
  - n = 9에서는 연속 실패 7점 중 3점이 실패했다(최대 4.1·10⁻⁵).
  - n = 10에서는 2점 중 1점이 실패했다(1.7·10⁻⁵).
- **H′(4류 이하)의 반증(e116–e117):**
  - 위 n = 9 실패 3점에서는 4류 이하 집합분할 전수(11,051개) 중 P̄를 달성하는 것이 없었다(차이 6·10⁻⁶–4.2·10⁻⁵, 부동소수점).
  - 첫 점 p = (0.0081, 0.024, 0.0348, 0.0384, 0.0433, 0.0446, 0.3587, 0.3903, 0.5778)은 정확히 5류에서 달성된다. 유일한 분할은 {1,4}, {2,3}, {5,6}, {7}, {8,9}이다.
  - → 필요한 류의 수는 n과 함께 자란다(n ≤ 8: 4, n = 9: 5). 정확 검증은 e118에서 진행 중이다.
- **그 점의 대칭 쌍대 증서(e119):**

  q = (4/3)N_R − N_R x₇ − (1/3)N_R(x₈+x₉) + (2/3)x₇ + (1/3)x₇(x₈+x₉) + x₈x₉ + (1/3)(x₁x₄ + x₂x₃)

  - R 안의 이차항은 **매칭** {1,4}, {2,3}(가중치 1/3)뿐이다.
  - 바깥 구조가 주는 안쪽 제약은 f(a)다.
    - a ≤ 4: f(a) = 0
    - a = 5: f(a) = 1/3
    - a = 6: f(a) = 2/3
  - 즉 "R에서 원소 하나를 지워도 가중치 1/3 이상, 전체는 2/3 이상"이라는 **결함 허용 덮개** 조건이다.
  - 최소 비용 해는 서로소인 두 변(1/3씩)이다. 곱 비용이므로 가장 작은 네 원소를 재배열 부등식에 따라 바깥-안쪽으로 짝지은 {1,4}, {2,3}이 최적이다.
- **새 가설 H6:** P̄(n,2,p) = min over 바깥 구조(T 쪽 소수 매개변수) of [바깥 값 + Λ_f(p_R)]. 여기서 Λ_f(p) = min{Σ w_ij p_ip_j : |S|만 의존하는 하한 f(|S|)를 모든 S에서 만족}이다.
  - 곱 비용에서 Λ_f의 최적해는 정렬 순서로 정해지는 구조(작은 원소들의 중첩 매칭, 클리크, 균등점, 별)로 구할 수 있다.
  - 참이면 류의 수가 자라도 다항식 시간이 가능하다.
  - 단 §5의 n = 8·9 반례에서 쓴 가중 분할(균형 분할)은 정렬만으로 정해지지 않는다. 그 경우와 어떻게 맞물리는지는 미해결이다.
- **H6 시험(e120–e121):**
  - f(s) = max(0, αs − β)(바깥 구조에서 나오는 꼴)와 곱 비용으로 Λ_f를 LP로 풀었다.
  - 최적 w가 "가장 작은 j개 원소 위의 a·K + b·(중첩 완전매칭)"(H6a)에 맞은 것은 120개 중 66개였다.
  - 나머지는 1/12, 1/9, 7/9 같은 값을 갖는 분수 구조였고, 작은 원소 밖의 변(예: (2,8)에 1/2)도 있었다.
  - → 안쪽 문제의 최적해는 단순한 정렬 구조로 정해지지 않는다. H6은 약해졌다.
- **현재 종합(2026-11-15):** k = 2 정확 계산의 복잡도는 미해결이다.
  - 고정 개수 묶음 집계(연속 C36, 임의 C37)는 반증되었다. 필요한 류 수는 n과 함께 자란다.
  - 최적 증서에는 균형/가중 분할, 중첩 매칭, 분수 구조가 섞여 나온다.
  - 수 분할 환원은 LP 평활화 때문에 막혔다(§8).
  - 증명된 양의 결과는 K1(상한 족), K2(특수 닫힌꼴), A2(상수배 근사, 작음)다.

## 13. 구간 수(run) 제한 LP와 가설 R3′ — 다항식 알고리즘 후보 (2026-11-15, e122–e131)
- **아이디어.** LP 기저해의 성질 때문에 최적 법칙은 원자가 많아야 1 + n + C(n,2)개다. 원자가 정렬 순서에서 단순한 모양이라면, 후보 원자가 다항식 개수인 LP 하나로 P̄가 정확히 나온다.
- **구간 수 제한.** 원자 x의 1-좌표가 정렬 순서에서 r개 이하의 구간(run)을 이루는 것만 허용한다(`pwbound.runs_lp`).
  - 원자 수는 O(n^{2r})다(n = 20, r = 3이면 60,460개).
  - 행은 1 + n + C(n,2)개다.
  - 이 LP는 늘 P̄의 하한이다.
- **수치(탐색):**
  - n = 7–9, 정의된 어려운 점(C36, C37 포함) 16점: r = 3이면 일치, r = 2이면 최대 1.2·10⁻⁴ 부족(e122).
  - n = 9–12, P̄ < 1인 132점: r = 3의 최대 차이 1.1·10⁻¹⁴, r = 2의 최대 차이 2·10⁻⁴(e123).
  - n = 8–10 적대적 탐색 28회 × 60단계: r = 3의 최대 차이 1.4·10⁻¹⁴(e124).
  - n = 12–14에서 전체 LP와 비교: 일치(≤ 9·10⁻¹⁶). n = 16에서 r = 5와 r = 3: 일치(e127).
  - k = 3은 n ≤ 9에서 r = 3으로 일치했다. k = 4는 r = 3이 실패(1.6·10⁻⁴)하고 r = 4가 일치했다(e126, n이 작아 약한 근거).
- **R3의 반례와 수정(e129–e130):**
  - n = 18의 한 점(P̄ = 1)에서 r = 3 원자로는 모멘트 자체를 맞출 수 없었다. 여유 변수 LP로 최소 위반 0.104를 확인했다.
  - 원인(증명됨, 간단): 원자 하나의 경계(xᵢ ≠ xᵢ₊₁) 수는 많아야 2r이다. 따라서 r-구간 법칙이 있으려면 Σᵢ P(xᵢ ≠ xᵢ₊₁) = Σᵢ (pᵢ + pᵢ₊₁ − 2pᵢpᵢ₊₁) ≤ 2r여야 한다.
  - 반면 P̄ < 1이면 정리 C4(k = 2 확실성 판정, 모든 n에서 증명됨)에 의해 LOO_j < 2인 j가 있다. 그러면 S₁ < 3이고, 위 합은 ≤ 2S₁ < 6 = 2·3이다. "3"이라는 수가 바로 이 경계와 맞는다.
- **가설 R3′(k = 2):** P̄(n,2,p) < 1이면 3-구간 이하 원자 LP의 값이 P̄와 같다.
- **R3′가 참이라면 알고리즘:**
  1. 모든 p_j < 1에서 LOO_j ≥ 2이면 P̄ = 1이다(정리 C4).
  2. 아니면 O(n⁶)개 변수의 LP를 푼다.
  - 이것이 R–N (a)의 k = 2 경우에 대한 다항식 시간 답이 된다. 증명은 아직 없다.
- **증명 단서(e128):** 제한 LP의 최적 쌍대 증서 q*는 2⁹개 전체 x에서 유효했다(n = 9 반례 점).
  - q*의 R 부분은 중첩(무지개) 매칭 {1,4}, {2,3}이다.
  - 최소 가중 s-부분집합을 "각 중첩 쌍에서 한 끝"으로 고를 때 구간({3,4,5,6} 등)으로 고를 수 있다. 그래서 tight 원자가 적은 구간을 가진다.
- **추가 시험(e131–e135):**
  - P̄ < 1(정리 C4로 판정)인 점만 보았다. n = 10, 12, 14에서는 전체 LP와 비교했고, 최대 차이는 6·10⁻⁸(n = 12 한 점, 풀이기 허용오차 수준)이었다. n = 16, 18, 20에서는 r = 4와 비교했고 일치했다(n = 20: 최대 8.9·10⁻¹⁶).
  - n = 10–12 적대적 탐색(전체 LP 대비): 최대 1.4·10⁻¹⁵.
  - 대안 구조 "임의 원소 ≤ 2개 + 접미 구간"은 최대 1.4·10⁻² 부족했고, "임의 원소 ≤ 2개 + 임의 구간"은 3.4·10⁻⁵ 부족했다(e134). → 3-구간이라는 일반형이 필요하다.
- **정확 검증(유리수):** C36 점, C37 점, n = 9 가중 분할 점에서 3-구간 원자 위의 정확한 실행 가능 법칙의 값이 정확한 쌍대 상한과 같았다. 즉 이 세 점에서 R3′가 정확히 성립한다(`scripts/verify_k2_aggregation_counterexamples.py`의 `check_three_runs`).
- **제한 쌍대의 구조(e133, 40점):** 대부분은 단순했다. 26점은 R 안 항이 0인 꼴(KHW형 등)이고, S₂형(모든 y = 1)도 있었다. 무지개 매칭 같은 복잡한 R–R 구조는 드물다.
- **원자 구조 세분(e136–e137):**
  - 최적 법칙이 쓰는 3-구간 원자를 보았다. 3구간이 필요한 7개 사례의 3-구간 원자 57개 모두에서 **마지막 구간이 최댓값 좌표를 포함하는 접미 구간**이었다.
  - 그래서 가설 R3″를 세웠다: "최댓값을 포함한 접미 구간을 떼면 구간이 ≤ 2개인 원자"(곧 ≤2-구간 원자 + 최댓값을 포함한 3-구간 원자, O(n⁵)개)만으로 P̄를 얻는다.
  - P̄ < 1인 70점(C36·C37 점 포함)에서 일치했다(최대 1.1·10⁻¹⁴).
  - k = 1의 R–N 극값 법칙(원자 {i}, {i, n})도 "접미 구간 밖에 1구간"이라는 같은 꼴이다. k = 1은 2구간이면 정확하고 1구간은 실행 불가였다(e138).
- **k ≥ 3(e126, e138):** k = 3은 n ≤ 11에서 3구간이면 일치했다. k = 4는 n ≤ 9에서 4구간이 필요했다. 일반 k의 규칙은 아직 불명확하다.
- **증명 상황:**
  - 직접 교환 논법은 그대로 통하지 않는다. 두 원자 사이의 원소 교환은 쌍 모멘트를 깨고, 모멘트를 보존하는 이동은 3차 이상의 부호 측도(m_{S,B})다.
  - 쌍대 쪽(제한 증서 q*의 전역 유효성)은 q*의 구조를 알아야 하는데, 일반 구조는 모른다.
  - **R3′/R3″의 증명은 미해결**이다.
- **반증 시도(e135):** n = 12–14에서 V4 − V3(4구간 LP − 3구간 LP)를 적대적으로 최대화했다(13회 × 25단계). 최대 3.3·10⁻¹⁵였다.
- **증명 경로 (a) 점검(e139):**
  - 최댓값 좌표 X_n으로 조건화하면 조건부 법칙 A(X_n = 1)와 B(X_n = 0)의 주변확률은 둘 다 p다(쌍별 독립에서 강제됨).
  - 쌍 모멘트는 π·A + (1−π)·B = ppᵀ만 만족하면 된다.
  - 어려운 두 점의 최적해에서 D = A − ppᵀ는 대부분 음(최소 −0.14)이지만 작은 양수(≤ 1.1·10⁻³)도 있었다. A와 B의 원자 모양도 더 단순하지 않았다.
  - → 이 형태의 귀납은 바로 닫히지 않는다.

## 14. R3′ 증명 시도 (2026-11-15, e139–e145)
- **강한 성질(e140):** 제한 LP의 최적 증서 q*에서, 각 크기 s의 최솟값 min_{|x|=s} q*(x)는 3구간 이하 집합에서 달성되었다(70/70). 그래서 증명 목표를 "q*의 구조 → 크기별 최솟값이 적은 구간에서 달성"으로 바꿀 수 있다.
- **q*의 구조는 다양하다(e141, 180점):**
  - R–R 부분이 0인 경우가 123점, 균등 32점, 접두 클리크·별·비교차 매칭 등이 나머지다.
  - 위쪽 묶음 T의 크기는 0–9로 퍼져 있다.
  - → 경우 나누기 증명은 길다.
- **안쪽 문제로의 축소는 실패(e142–e145):**
  - 안쪽 LP Λ_f의 *전체* 최적해 w에서는 크기별 최솟값이 2구간 집합에서 달성된다(144/144).
  - 그러나 Λ_f를 2구간 제약만으로 푼 값은 전체와 자주 다르다. f = max(0, αs − β)에서 33/79, f_t에서 42/80이었다. 일반 볼록 f에서는 차이가 최대 13%였다.
  - 안쪽 쌍대(순위 1 가중 그래프의 분수 클리크 채우기)에서 "접두 ∪ 접미(무지개)" 클리크만 쓰면 단일 크기에서 최대 90% 부족하고, 2구간 클리크만 쓰면 19% 부족했다(e143).
  - → R3′는 바깥과 안쪽의 *공동* 최적화에서만 성립한다. 바깥을 고정한 축소로는 증명되지 않는다.
- **조건화 귀납도 그대로는 닫히지 않는다(e139, §13).**
- 남은 착안:
  - 경계 수 부등식(Σ P(xᵢ ≠ xᵢ₊₁) < 6)이 "3"을 설명한다. 이것을 원자별 주장으로 바꾸는 교환 논법이 필요하다.
  - 원문제의 3차 이동 m_{S,B}(|B| ≥ 2이면 목적함수가 변하지 않음)를 쓸 수 있는 원자가 언제 존재하는지 분석해야 한다.
- **추가 반증 시도(e146):** 다중 척도 사례(3–5개 척도에 값이 몰린 p)를 n = 9–12에서 적대적으로 탐색했다(65회). 최대 차이는 7.5·10⁻¹⁴였다. R3′는 유지된다.
- **R3‴ 반증(e147):** "크기 ≤ 3 원자 + 2구간 이하 원자"로는 부족했다(최대 1.8·10⁻⁴). 큰 원자도 3구간이 필요할 때가 있다.
- **증명 상황 요약:** 시도한 경로는 다음 넷이고, 아직 어느 것도 닫히지 않았다.
  - (a) 최댓값 조건화 귀납: 조건부 쌍 모멘트가 곱이 아니어서 같은 문제 꼴로 닫히지 않는다.
  - (b) 쌍대 q*의 구조 분류: 구조가 다양하다.
  - (c) 바깥 고정 후 안쪽 축소: 거짓이다.
  - (d) 원문제 교환: 쌍 모멘트 보존 이동이 3차 이상이라, 이웃 원자가 있어야 한다.
  - "3"은 기대 경계 수(< 6)와 맞지만, 원자별 주장으로 바꾸는 논법이 없다.

## 15. R3′ 반증 (2026-11-15, e148–e159)
- **정렬의 역할(e148):** 무작위 순서에서는 3구간으로 최대 1·10⁻²가 부족했고, 4구간이면 맞았다(n ≤ 9). 정렬 순서(또는 역순)에서는 3구간이 맞았다.
- **동일·두 값 주변확률(e149):** 3구간으로 정확했다. 설명: BP 최적 크기 지지가 {0,1,2} 또는 {0,2,n}이다. 크기 ≤ 3인 집합은 자동으로 ≤ 3구간이고, 전부 1인 집합은 1구간이다.
- **k = 1 재검토(e150–e157):**
  - 처음에는 "k = 1은 2구간이면 충분"(e138)이라고 보았다. 그러나 작은 같은 값이 많은 구조(예: 0.04×8, 0.05, 0.1, 0.1, 0.3)에서 2구간은 KHW 값보다 작았다. 차이는 n과 함께 커졌다(n = 12: 0.009, n = 18: 0.027). 3구간이면 정확했다(n ≤ 18).
  - 원인: 같은 값 좌표 쌍의 쌍 확률은 거리와 무관하게 같아야 한다. 구간은 가까운 쌍을 더 자주 덮는다.
  - 부수 결과(탐색): KHW < 1이면 "접미 ∪ 원소 ≤ 1개" 구조의 법칙이 무작위 116/116에서 실행 가능했다. 질량은 c·p_i(p_j − p_{j−1}) 꼴의 닫힌꼴이다. 하지만 위의 구조적 사례에서는 실행 불가였다.
- **k = 2 반례(e158–e159, 부동소수점):** p = (0.0219×6, 0.0259, 0.0278, 0.0288, 0.0398, 0.3486, 0.3688, 0.4033), n = 13.
  - min LOO = 0.971 < 2이므로 정리 C4에 의해 P̄ < 1이다.
  - 전체 LP는 P̄ = 0.64978183이다.
  - 3구간 LP는 0.64900360이다(7.8·10⁻⁴ 부족). 4구간 LP는 0.64978183로 일치한다.
  - → **가설 R3′는 거짓이다.** 무작위·적대적 탐색(수백 점)이 "작은 같은 값이 많은" 구조를 표본으로 뽑지 못해 놓쳤다.
- **의미:** 필요한 구간 수가 n(또는 작은 같은 값의 개수)과 함께 자라는지가 이제 핵심이다. 자라면 "고정 구간 수 LP → 다항식 시간" 경로는 닫힌다.
- **필요한 구간 수는 자란다(e160–e161).** 반례와 같은 구조에서 작은 같은 값의 개수 m만 늘렸다(작은 값 합은 고정).
  - m = 6(n = 13): V3 < V4 = V5 = P̄
  - m = 8(n = 15): V3 = 0.64835221 < V4 = V5 = 0.64984178
  - m = 10(n = 17): V4 = 0.6498727489 < V5 = 0.6498768043. 차이 4.06·10⁻⁶이고, HiGHS 단체법과 내점법이 10자리까지 같았다.
  - → 고정된 구간 수 r로 제한한 LP는 정확하지 않다. "구간 수 유계 → 다항식 시간" 경로는 닫혔다(부동소수점 근거. 유리수 증서는 아직 없다).
- **현재 종합:**
  - 정확 계산(R–N (a), k = 2)에 대해 반증된 다항식 크기 축약은 셋이다.
    - 고정 개수 묶음 집계: 연속 C36, 임의 C37
    - 고정 구간 수 원자: R3′(n = 13), 4구간(n = 17)
  - 최적 법칙은 "거의 같은 작은 좌표가 많을수록" 더 복잡한(구간이 많은) 원자를 필요로 한다.
  - 복잡도는 여전히 미해결이다. 구조가 n과 함께 자라므로 난해성 쪽 가능성이 이전보다 커졌다. 다만 정확히 같은 값의 묶음은 대칭화로 정확히 집계되므로, 난해성 환원은 "거의 같은 값"을 이용해야 한다.

## 16. 구간 설계 LP와 가설 S3 (2026-11-15, e162–e167)
- **착안.** 반례의 원인은 같은(또는 거의 같은) 값의 작은 좌표들이다. 그런 묶음에서 최적 법칙은 "구간 안에서 c개를 균등하게 고르는" 대칭 설계를 쓴다. 이것을 원자로 쪼개면 구간 수가 커진다. 그래서 LP의 열을 원자가 아니라 **"서로소인 구간 ≤ r개, 각 구간 [a,b]에서 c개를 균등 추출(구간끼리 독립)"인 법칙**으로 둔다(`pwbound.segment_lp`).
  - 열의 모멘트는 닫힌꼴이다: P(i) = c/L, 같은 구간 쌍 c(c−1)/(L(L−1)), 다른 구간 쌍은 곱이다.
  - 크기가 결정적이라 목적함수가 선형이다.
  - c = L이면 보통의 구간 원자이므로, 구간 LP를 포함한다.
  - 열 수는 O(n^{3r})로 다항식이다.
- **결과(부동소수점, 전체 LP 대비):**
  - R3′ 반례(n = 13): r = 2이면 2.9·10⁻⁴ 부족, r = 3이면 정확. n = 15 변형도 r = 3이면 4·5구간 LP 값과 같았다.
  - 반례의 작은 값을 최대 6% 흔들어 모두 다르게 만든 4점: r = 3이면 정확했다(3구간 원자 LP는 7.3–7.8·10⁻⁴ 부족).
  - 같은/거의 같은 값의 묶음을 2–3개 둔 다중 척도 8점(n = 7–14): r = 3이면 정확했다.
  - k = 1: 2구간 원자가 실패한 구조(n = 12, 14, 16)와 거의 같은 값의 무작위 3점에서 r = 2이면 정확했다(KHW 닫힌꼴과 비교).
- **쓰인 열의 모양(e166):** "구간에서 1개" + "위 묶음에서 1개", "위 3개 중 2개", 가끔 "구간에서 3–4개". 대칭 설계가 핵심이다.
- **가설 S3(k = 2):** P̄ < 1이면 r = 3인 구간 설계 LP의 값이 P̄와 같다. (k = 1의 대응: r = 2.)
  - 참이면 O(n⁹)개 열의 LP로 다항식 시간이다. 열 모양을 줄일 여지가 있다.
  - 증명은 없다. 적대적 시험 진행 중이다(e165).
- **정확 검증(유리수):** R3′ 반례(n = 13)에서 다음을 확인했다.
  - 정확한 최적 쌍대 증서: 최적 받침 위 등식을 유리수로 풀었고, 2¹³개 상태 전부에서 유효했다. 이로써 P̄ = 1949345491/3000000000이다.
  - 구간 설계 혼합의 정확한 법칙이 이 값을 그대로 달성한다.
  - 3구간 원자 법칙의 최댓값은 정확히 7.78·10⁻⁴ 작다. → claims C38
- **적대적 시험(e165, e171):** n = 10–13에서 구간 설계 LP의 차이를 최대화했다(같은 값 묶음과 근접 동률을 일부러 만듦). 최대 1.27·10⁻⁷였는데, 엄격한 허용오차와 두 풀이법으로 다시 풀자 12자리까지 일치했다(수치 오차). S3의 반례는 없다.
- **k = 1 보조정리 J‴(탐색, e168–e170):** Σq < 1이고 q_max ≤ 1/κ이면, 주변확률 q, 쌍 확률 κ·q_iq_j인 법칙을 "접미 구간(전부) ∪ 설계 구간 ≤ 1개" 열의 혼합으로 만들 수 있다(150/150). 설계 구간 하나만으로는 불가능하다(위반 0.44). 이것이 증명되면 KHW 상한이 2구간 설계 구조로 달성된다는 것이 따른다. k = 2 증명의 원형이 된다.
- **열 축소(e172–e175):**
  - n ≤ 13의 어려운 14점에서 "설계 구간 ≤ 1개"와 "설계 개수 c ≤ 2"는 각각 단독으로는 정확했다.
  - 둘을 합치면 n = 15, 17에서 5구간 LP보다 3–6·10⁻⁵ 작았다.
  - "설계 구간 ≤ 1개"만 둔 족은 n = 15, 17에서 5구간 LP와 같았다. n = 17에서는 6·7구간 LP도 같은 값 0.6498768043이었으므로 사실상 참값으로 본다.
  - → **정제 가설 S3a:** P̄ < 1이면 "구간 ≤ 3개, 그중 균등 추출(c < L) 구간은 ≤ 1개, 나머지는 전부 포함 구간"인 열의 LP가 P̄와 같다. 열 수는 O(n⁷)이다.
