# 문제 정의와 고정 가정

## 문제

X1, …, X5 ∈ {0,1}는 i번째 검사의 오류 여부다.

- P(X1=1) = P(X2=1) = p (그룹 G1 = {1,2})
- P(X3=1) = P(X4=1) = P(X5=1) = q (그룹 G2 = {3,4,5})
- 서로 다른 두 변수는 모두 독립이다(10쌍). 다섯 변수의 상호 독립은 가정하지 않는다.

구할 것: M(p,q) = max P(X1+…+X5 ≥ 3)와 이를 달성하는 결합분포.
연구 범위: 0 ≤ p ≤ q ≤ 1 (경계 포함).

표기: A = X1+X2 ∈ {0,1,2}, B = X3+X4+X5 ∈ {0,1,2,3}, S = A+B.

## 고정 가정

1. **쌍별 독립의 동치 조건.** 이진변수 Xi, Xj에 대해 주변확률이 주어지면 Xi ⊥ Xj ⇔ P(Xi=1, Xj=1) = P(Xi=1)P(Xj=1)이다. 나머지 세 칸은 주변확률에서 결정된다. 검증기는 그래도 2×2 네 칸을 모두 직접 검사한다.
2. **최댓값의 존재.** 실행 가능 집합은 32차원 단체 안의 다면체다. 상호 독립 분포 Bin(2,p)×Bin(3,q)가 항상 실행 가능하므로 공집합이 아니고, max가 달성된다.
3. **영역.** 0 ≤ p ≤ q ≤ 1이며 p=0, q=1, p=q 같은 퇴화 경계를 포함한다.
4. **p↔q 대칭을 쓰지 않는다.** 그룹 크기가 2와 3으로 다르다. 계산에서는 항상 (p, q) 순서를 고정한다.
5. **목적 사건.** {S ≥ 3}은 12상태 (a,b) 중 6개 — (0,3),(1,2),(1,3),(2,1),(2,2),(2,3) — 이고, 32상태 중 C(5,3)+C(5,4)+C(5,5) = 16개다.
6. **최대화 분포는 "하나의" 최대화 분포다.** 32상태 모형에서 최대화 분포가 유일하다고 주장하지 않는다.

## 비트열 규약

32상태는 문자열 `"x1x2x3x4x5"`로 쓴다. 왼쪽 첫 글자가 X1이다. 예: `"10011"`은 X1=1, X2=0, X3=0, X4=1, X5=1.
