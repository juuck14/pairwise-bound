# 쌍별 독립에서 두 모멘트 상한(BP)은 언제 정확한가 — 일반 n, k

상태 표기는 `notes/claims.md`와 같다. 이 문서의 주장 ID(E, C, S, L 계열)는 claims의 C15–C25에 대응한다.

## 0. 설정과 표기

- X = (X_1, …, X_n) ∈ {0,1}^n, 주변확률 p = (p_1, …, p_n), 모든 쌍이 독립(P(X_iX_j=1) = p_ip_j). 이런 법칙을 "p의 쌍별 독립 법칙"이라 부른다.
- S = X_1 + … + X_n, 정수 k ∈ [1, n].
- **P̄(n,k,p)** = max P(S ≥ k) (최대는 p의 쌍별 독립 법칙 전체에서). Ramachandra–Natarajan(R–N, arXiv:2006.00516 v6)의 표기다. 원래 문제의 M(p,q)는 P̄(5,3,(p,p,q,q,q))다.
- S₁ = Σ p_i, S₂ = Σ_{i<j} p_ip_j. 쌍별 독립이면 E[S] = S₁, E[C(S,2)] = S₂다.
- **BP(S₁,S₂)** = max{ Σ_{s≥k} v_s : v는 {0..n} 위의 확률, Σ s v_s = S₁, Σ C(s,2) v_s = S₂ }. Boros–Prékopa(1989)의 두 모멘트 상한이며 R–N §1의 식 `BorosPrekopa`다. 항상 P̄ ≤ BP다.
- BP의 최적 법칙 v̄의 지지집합을 **K**라 한다. R–N Theorem 4.1이 쓰는 세 경우(동일 주변확률의 최적 지지)는 다음과 같다.
  - (a) BP = 1: K = {j−1, j, n}, j−1 ≥ k
  - (b) K = {0, k, n}
  - (c) K = {i−1, i, k}, 1 ≤ i ≤ k−1
- **층** L_s = {x : |x| = s}.
- **LOO_j** = Σ_{l≠j} p_l (leave-one-out 합).
- φ(x) = (x_1, …, x_n, (x_ix_j)_{i<j}) ∈ ℝ^{n+C(n,2)}, φ(p) = (p, (p_ip_j)_{i<j}).

이 문서의 질문: **어떤 p에서 P̄(n,k,p) = BP인가? 아니면 무엇이 그것을 막는가?** R–N은 동일 주변확률(Theorem 4.1)과 "n−1개 동일 + 1개"(Prop. 4.5)에서만 tight함을 보였고, Example 3.2(n=12)에서 서로 다른 주변확률인데도 BP가 tight한 k가 있음을 수치로만 보고했다.

## 1. 기본 보조정리

**보조정리 0 (층 기준).** P̄ = BP일 필요충분조건은 S의 법칙이 BP-최적인 p의 쌍별 독립 법칙이 있는 것이다. BP-최적 법칙이 유일하고 지지가 K이면, 이는 ∪_{s∈K} L_s 위에 사는 p의 쌍별 독립 법칙이 있는 것과 같다.

*증명.* 쌍별 독립 법칙 θ의 S-법칙은 BP 문제에서 실행 가능하고 목적값이 P_θ(S≥k)다. 그래서 P̄ ≤ BP이고, 등호는 최적 θ의 S-법칙이 BP-최적일 때 성립한다. 유일하면 그 S-법칙은 v̄이므로 θ는 K의 층들 위에 산다. 역으로 θ가 K의 층 위에 살면, S-법칙은 K 위에서 세 모멘트 방정식(행 1, s, C(s,2))을 만족하고 이 계는 해가 하나뿐이므로 v̄다. ∎ (표준 LP 논법이다.)

**보조정리 1 (조건부 평균).** p의 쌍별 독립 법칙에서 다음이 성립한다.
- p_j > 0이면 E[S | X_j = 1] = 1 + LOO_j
- p_j < 1이면 E[S | X_j = 0] = LOO_j

*증명.* l ≠ j에 대해 E[X_l | X_j=1] = p_lp_j/p_j = p_l이고, E[X_l | X_j=0] = (p_l − p_lp_j)/(1−p_j) = p_l이다. ∎

(사소하지만 이 문서의 모든 장애 조건이 여기서 나온다. 주변확률이 다르면 이 조건부 평균이 좌표마다 달라진다. 그런데 BP-최적 법칙은 S를 소수의 층에 몰아넣는다. 이 둘이 충돌하는 것이 BP가 깨지는 기본 원인이다.)

**보조정리 M (단조성).** P̄(n,k,p)는 각 좌표 p_t에 대해 비감소다.

*증명.* δ ≤ p_t라 하자. θ를 (p_{−t}, δ)의 최적 쌍별 독립 법칙, θ′를 θ에서 X_t를 1로 바꾼 법칙이라 한다. θ′도 쌍별 독립이다(X_t ≡ 1은 모든 변수와 독립). λ = (1−p_t)/(1−δ)로 두면 λθ + (1−λ)θ′의 주변확률은 p이고, 쌍 (i,t)의 확률은 λδp_i + (1−λ)p_i = p_ip_t이며, 다른 쌍은 그대로다. θ′ 아래의 S는 θ 아래보다 점별로 크거나 같다. ∎ (R–N이 Theorem 2.3 증명 (2)에서 k=1에 쓴 혼합 논법을 일반화한 것이다.)

## 2. 확실성 판정 (BP = 1인 경우)

**정리 C1 (필요조건, 모든 n, k).** P̄(n,k,p) = 1이면, p_j < 1인 모든 j에 대해 LOO_j ≥ k다.

*증명.* 최댓값은 달성된다(실행 가능 집합이 콤팩트). S ≥ k인 쌍별 독립 법칙에서 보조정리 1을 쓰면 E[S | X_j=0] = LOO_j ≥ k다. ∎

**정리 C2 (충분조건이 증명된 경우).** 다음 경우에는 C1의 조건이 충분하다.
- k = 1: R–N Theorem 2.3(“P̄(n,1,p) = min(Σp − p_max Σ_{others}, 1)”)과 같은 조건이다. 재현이다.
- k = n: 조건은 모든 p_j = 1과 같다.
- k = n−1: 조건은 많아야 하나의 p_j가 1보다 작다는 것이다. 그 좌표만 Bern(p_j)이고 나머지가 1인 법칙이 된다.
- **k = n−2 (새 증명):** q = 1 − p, Y = 1 − X로 두면 S ≥ n−2는 "Y 중 많아야 2개가 1"이다. 다음과 같이 둔다.
  - P(Y = e_i + e_j) = q_iq_j
  - P(Y = e_i) = q_i(1 − Σ_{l≠i} q_l)
  - P(Y = 0) = 1 − Σq + Σ_{i<j} q_iq_j

  이 법칙은 Y의 쌍별 독립 법칙이다. 질량이 음이 아닐 조건은 q_i > 0인 모든 i에 대해 Σ_{l≠i} q_l ≤ 1이고, 이는 p로 LOO_i ≥ n−2(C1의 조건)와 같다. P(Y=0) ≥ 0은 이 조건에서 따라온다: q_1을 양수 중 최솟값, T = Σ_{l≠1} q_l ≤ 1이라 하면 P(Y=0) = (1−q_1)(1−T) + Σ_{1<i<j} q_iq_j ≥ 0이다. 코드: `general.top2_complement_law`, 테스트 `test_top2_complement_law_is_exact_and_certain`.
- 동일 주변확률: R–N Theorem 4.1(a)(b)로 P̄=1 ⇔ k ≤ (n−1)p이다. 이는 C1의 조건과 같다. 재현이다.
- 동일 주변확률 근방: 정리 L(a)를 R–N 경우 (a)의 내부에 적용하면 된다.

**따름정리 (원래 문제의 C12를 정리로).** (p,p,q,q,q)는 n=5, k=3=n−2인 경우다. 따라서 M(p,q) = 1 ⇔ q = 1, 또는 (q ≥ 3/2 − p이고 q ≥ 1 − p/3)이다. 이전에는 V18 facet 부등식에서 컴퓨터 보조로 얻었는데, 이제 사람이 읽을 수 있는 증명이 있다.

**추측 C (일반 충분성).** 모든 n, k, p에 대해 P̄(n,k,p) = 1 ⇔ "p_j < 1인 모든 j에 대해 LOO_j ≥ k"이다.

**명제 C3 (두 값 주변확률의 환원).** α개 좌표가 a, β개 좌표가 b이고 β ≥ 2, 0 < a ≤ b < 1, αa + (β−1)b = k라 하자(이 족의 최소점). S ≥ k인 쌍별 독립 법칙이 있을 필요충분조건은, 어떤 ω ∈ [0,1]에 대해 다음 두 1차원 문제가 모두 풀리는 것이다.
- (W) {max(0,k−α), …, min(k,β−1)} ∪ {β} 위의 확률 w가 있어 다음을 만족한다: w_β = ω, Σ s w_s = βb, Σ s(s−1) w_s = β(β−1)b².
- (N) {max(0,k−β), …, α} 위의 측도 ν가 있어 다음을 만족한다: 총질량 ω, Σ x ν_x = (k−β)ω + b, Σ x(x−1) ν_x = (k−β)(k−β−1)ω + C, 여기서 C = k − αa² + 2b(k−β) − (β−1)b².

*증명.*
- (⇒) 그룹 안 순열 평균화로 그룹 교환가능성을 가정해도 된다(원래 문제의 정리 R과 같은 논법). B = b-좌표 합, A = a-좌표 합이다.
- b-좌표 j에서 보조정리 1에 의해 E[S | X_j=0] = LOO_j = k이고 S ≥ k이므로, X_j = 0이면 S = k다. 교환가능성 때문에 B < β인 모든 (A,B)에서 A = k − B다.
- w를 B의 법칙, ν를 {B=β} 위의 A의 (비정규화) 법칙이라 하자. 모멘트 조건 E[B], E[B(B−1)]이 (W), E[A], E[A(A−1)]이 (N)이 된다. 정리하는 데 경계 관계 αa = k − (β−1)b를 쓴다.
- 교차 조건 E[AB] = αβab는 (W)와 E[A]에서 자동으로 따라온다: E[AB] − βE[A] = −E[(β−B)(k−B)] = −β(1−b)(k−(β−1)b).
- (⇐) 같은 식을 거꾸로 읽고 그룹 안에서 균등하게 나누면 된다. ∎

- 단조성(보조정리 M)과 동일 주변확률 경우(R–N)를 함께 쓰면, 두 값 주변확률 전체에 대한 추측 C는 "모든 최소점에서 (W)와 (N)의 ω-구간이 겹친다"와 동치다.
- 탐색: 무작위 최소점 5,182개(α ≤ 10, 2 ≤ β ≤ 10)에서 모두 겹쳤다(`python -m scripts.explore_exactness twovalued-reduced`). β = 2이면 ω = b²로 강제되고, k = n−2이면 정리 C2가 이미 덮는다.
- 남은 단계(2026-10-29 기준): 두 구간의 끝점을 닫힌꼴로 구해 겹침을 증명하는 것. 2026-10-30에는 다른 경로(아래 명제 C7)로 두 값 경우를 1차원 부등식 두 개로 줄였다.
- 막힌 지점(시도한 접근과 실패 이유)은 `notes/research_reassessment.md` §6에 있다. 핵심은 이것이다: 한 좌표로 조건화하면 조건부 법칙들의 쌍 확률이 곱 꼴이 아니게 되어 귀납 가정이 닫히지 않는다. 또 2n개 조건부 평균 부등식은 곱 꼴이 아닌 일반 모멘트 점에서는 충분하지 않다(반례를 수치로 찾음, J19). 따라서 증명은 곱 구조를 실제로 써야 한다.

### 2.1 벗겨내기(peeling) 구성: k = 2의 증명과 일반 k의 환원 (2026-10-30)

아이디어: 최소점에서 법칙을 L = (1−s)·D + s·R로 찾는다.
- R: "최댓값 좌표가 모두 1이고 나머지는 쌍별 독립"인 법칙. 귀납으로 처리한다.
- D: 정확히 k개가 1인 법칙(k-설계).

k-설계의 행합 조건이 s와 R의 주변확률을 하나로 정한다. 그렇게 정해진 D의 2×2 표는 모두 음이 아니다(보조정리 P3). 따라서 남는 것은 "그런 1·2차 포함확률을 갖는 k-설계가 있는가"뿐이다. k = 2(또는 n−k = 2)이면 이것이 자동이다.

**보조정리 R (최소점으로의 환원).** p가 C1의 조건을 만족한다고 하자. 1인 좌표는 빼고 k를 그 수만큼 줄인다(줄인 k가 0 이하이면 자명). 그러면 p′ ≤ p(좌표별)인 **최소점** p′이 있다. 최소점은 b = max p′ < 1이 적어도 두 좌표에서 달성되고 Σp′ − b = k인 점이다.

*증명.*
1. 최댓값이 하나뿐이면 그것을 두 번째로 큰 값으로 낮춘다. 그 좌표의 LOO는 그대로이고, 다른 좌표의 LOO는 새 최댓값 좌표의 LOO 이상이므로 조건이 유지된다.
2. 그다음 p′ = t·p로 줄인다. 여기서 t = k/(Σp − b) ≤ 1이다. 동률 구조는 유지되고 Σp′ − b′ = k가 된다.
3. 보조정리 M에 의해 P̄(p′) = 1이면 P̄(p) = 1이다. ∎

코드: `general.minimal_point_below`(정확). 이하에서는 다음 표기를 쓴다.
- p는 최소점이다.
- B = {j : p_j = b}, β = |B| ≥ 2.
- A = 나머지 좌표이고, a_i = p_i < b이다.
- (β−1)b + Σ_A a_i = k이다.

**구성.** s ∈ (0,1)과 z ∈ [0,1]^n(단, z_B = 1)을 고르고 다음을 둔다.
- R: X_B ≡ 1이고, X_A는 주변확률 z_A의 쌍별 독립 법칙이며 S_A ≥ k−β이다. k ≤ β이면 S_A 조건이 없으므로 독립 곱으로 충분하다.
- D: 크기 k인 집합 위의 확률(k-설계)이다. 포함확률은 다음과 같다.
  - P(l ∈ T) = π_l := (p_l − s z_l)/(1−s)
  - P(l,t ∈ T) = Π_lt := (p_lp_t − s z_lz_t)/(1−s)
- L = (1−s)D + sR.

이때 L의 주변확률은 p이고 쌍 확률은 p_lp_t이다. R의 쌍 확률이 z_lz_t이기 때문이다. 또 D에서는 S = k이고 R에서는 S = β + S_A ≥ k이므로, L에서 S ≥ k가 거의 확실하다.

D가 k-설계이려면 Σπ = k와 행합 조건 Σ_{t≠l} Π_lt = (k−1)π_l이 성립해야 한다. 이를 정리하면 다음 두 조건이 된다.
- l ∈ B의 행: Σ_A z_i = k − β + b/s
- i ∈ A의 행: (1 − z_i)(b − s z_i) = (1 − a_i)(b − a_i)

유도: Σ_{t≠l} Π_lt = [p_l(k + b − p_l) − s z_l(β + Σ_A z − z_l)]/(1−s)로 쓰고, 이를 (k−1)π_l과 같게 놓는다. Σπ = k는 B의 행 조건에서 따라온다.

**보조정리 P1 (곡선).** 0 < s ≤ b < 1, 0 ≤ a ≤ b라 하자. f_s(y) = (1−y)(b−sy)는 [0,1]에서 순감소하고 f_s(0) = b ≥ f_1(a) ≥ 0 = f_s(1)이다. 따라서 f_s(y) = f_1(a)는 [0,1]에서 해 y = y_s(a)를 하나만 가진다. 이 해는 다음을 만족한다.
- (i) a ≤ y_s(a)이다. f_s(a) − f_1(a) = a(1−a)(1−s) ≥ 0이기 때문이다.
- (ii) y_{b²}(a) = a/b이다. 직접 대입하면 확인된다.
- (iii) s ≤ b²이면 y_s(a) ≤ a/√s이다. f_s(a/√s) − f_1(a) = a(1−√s)(1 − b/√s) ≤ 0이고 f_s가 감소하기 때문이다.
- (iv) y_s(a)는 s ∈ (0, b²]에서 s에 대해 연속이다(음함수 정리; b < 1이면 s ≤ b² < b이므로 f_s′(y) ≤ s − b < 0).

**보조정리 P2 (s의 선택).** Φ(s) = Σ_A y_s(a_i) − (k − β + b/s)라 하자.
- Φ는 (0, b²]에서 연속이다.
- s → 0+이면 Φ → −∞이다.
- (ii)에서 Φ(b²) = (Σ_A a_i)/b − k + β − 1/b = (k−1)(1−b)/b ≥ 0이다.

따라서 Φ(s) = 0인 s ∈ (0, b²]가 있다. 이 s와 z_A = y_s(a_A)를 쓴다. 코드는 `general.peeling_parameters`(부동소수점 이분법)이다.

**보조정리 P3 (D의 모멘트).** 이렇게 정한 (s, z)에서 다음이 성립한다.
- Σπ = k이고 행합 조건이 성립한다(구성에서).
- 모든 l ≠ t에 대해 2×2 표의 네 칸 Π_lt, π_l − Π_lt, π_t − Π_lt, 1 − π_l − π_t + Π_lt가 모두 ≥ 0이다.

*증명.* s ≤ b²과 P1(iii)에서 i ∈ A에 대해 √s z_i ≤ a_i이고 s z_i ≤ √s a_i ≤ b a_i이다. 또 s ≤ b²이다. 이로부터 다음이 나온다.
- Π_lt ≥ 0: (B,B) 쌍은 b² − s ≥ 0, (B,A) 쌍은 b a_i − s z_i ≥ 0, (A,A) 쌍은 a_ia_t − (√s z_i)(√s z_t) ≥ 0이다.
- π_l − Π_lt = [p_l(1−p_t) − s z_l(1−z_t)]/(1−s) ≥ 0: z_t ≥ p_t(P1(i), z_B = 1)이고 s z_l ≤ p_l이기 때문이다.
- 1 − π_l − π_t + Π_lt = [(1−p_l)(1−p_t) − s(1−z_l)(1−z_t)]/(1−s) ≥ 0: z ≥ p이기 때문이다. ∎

**정리 C4 (k = 2, 새 증명).** 모든 n과 p에 대해 다음이 성립한다.

P̄(n,2,p) = 1 ⇔ p_j < 1인 모든 j에 대해 LOO_j ≥ 2

*증명.*
- (⇒)는 C1이다.
- (⇐) 보조정리 R로 최소점만 보면 된다. k = 2이면 D는 2-집합 {l,t}에 질량 Π_lt를 두는 측도다.
  - P3에 의해 이 질량은 음이 아니다.
  - 행합 조건 때문에 총질량은 (1/2)Σπ_l = 1이고 주변확률은 π다.
  - β ≥ 2 = k이므로 R은 "X_B ≡ 1, X_A는 독립 Bernoulli(z_A)"로 충분하다.
  - 따라서 L은 S ≥ 2가 거의 확실한 p의 쌍별 독립 법칙이다. ∎

참고 사항:
- 원자 수는 C(n,2) + 2^{|A|} 이하다.
- k = 1이면 Φ(b²) = 0이므로 s = b², z_A = a_A/b로 둘 수 있다. 그러면 Π ≡ 0(1-설계)이고 D에서 l을 뽑을 확률은 p_l/(1+b)이다. R–N Theorem 2.3 증명의 "p_i/p_n" 구조와 같은 모양이다(재현).
- 검증은 정확·부동소수점 둘 다 했다.
  - 정확(분수): β=2 두 값 족 `general.two_valued_k2_instance`이다. 이 족에서는 s, z가 유리수다. 테스트는 `test_theorem_c4_exact_two_valued`이며 6개 사례에서 verify_law와 S ≥ 2를 정확히 확인했다.
  - 부동소수점: `test_theorem_c4_float_random`은 무작위 최소점 150개 이상에서 모멘트 오차 < 10⁻¹²를 확인한다. P1–P2는 `test_peeling_curve_lemma`(sympy 항등식 포함)와 `test_peeling_phi_at_b_squared`(정확)가 확인한다.

**명제 C5 (일반 k의 환원).** p가 (n,k)의 최소점이고 (s, z)를 P2로 정했다고 하자. 다음 둘이 성립하면 P̄(n,k,p) = 1이다.
- (i) 1·2차 포함확률이 (π, Π)인 k-설계가 있다.
- (ii) (k > β일 때만 필요) A 위에서 주변확률 z_A, 문턱 k−β의 확실성 법칙이 있다.

(ii)는 귀납으로 처리된다. z_A는 문턱 k−β의 C1 조건을 만족한다. 실제로 Σ_A z − z_i = k − β + b/s − z_i ≥ k − β이다(z_i ≤ 1 ≤ b/s). 따라서 (|A|, k−β)에서 추측 C가 성립하면 (ii)가 성립한다. |A| < n이다.

따름 결과:
- **추측 D**(아래)가 참이면, n에 대한 귀납으로 추측 C가 참이다.
- (i)은 min(k, n−k) ≤ 2이면 P3에서 자동이다.
  - k = 2: 위의 2-설계.
  - k = n−2: 여집합이 2-설계다. 질량은 1 − π_l − π_t + Π_lt ≥ 0이고 총합은 1이다.
- 그래서 C5는 정리 C2의 k = n−2를 (귀납으로) 다시 증명한다. 추측 C는 k ∈ {1, 2, n−2, n−1, n}에서 확정되고, n ≤ 5는 전부 해결된다. 첫 미해결 경우는 **n = 6, k = 3**이다.

**추측 D (벗겨내기 설계의 존재).** 3 ≤ k ≤ n−3인 모든 최소점에서 C5(i)의 k-설계가 있다. 이는 가중 완전그래프 (Π_lt)가 분수 K_k-분해를 갖는 것과 동치다. 분수 K_k-분해란 크기 k 집합 위의 측도로서, 각 변 {l,t}를 포함하는 집합들의 질량 합이 Π_lt인 것이다.

D의 구조:
- 공분산은 Cov(1_l, 1_t) = −(s/(1−s)²) w_lw_t (w = z − p ≥ 0, l ≠ t)이고, 대각은 π_l(1−π_l)이다.
- 행합 조건을 쓰면 Cov = κ(diag ω − ωωᵀ)이다. 여기서 ω = w/Σw, κ = b²/s ≥ 1이다. 즉 "한 번 뽑는 범주형 분포 공분산의 κ배"다.
- 균등 ω이면 크기 k 단순임의추출(SRS)이 이 꼴이다(κ = k(n−k)/(n−1)). 동일 주변확률 최소점에서 D는 정확히 SRS다. 그러므로 추측 D는 "SRS의 가중 일반화가 존재한다"는 주장이다.

증거(부동소수점 LP):
- 최소점 553개에서 모두 실현 가능했다(LP 위반 0, `python -m scripts.explore_exactness peeling`). 범위는 n = 6–10, 3 ≤ k ≤ n−3, β ∈ {2, 3, n−k−1}이다. 표집 방식은 균등, b ≈ 1, b ≈ k/(n−1), 뾰족한 a, 두 계급의 다섯 가지다.
- 같은 분해를 q-세계(Y = 1 − X)에서 독립적으로 구현한 탐색에서도 720개가 모두 실현 가능했다(J21).
- 두 값 최소점 182,726개에서는 아래 명제 C7의 1차원 조건이 모두 성립했다.

**명제 C7 (두 값 최소점에서 추측 D의 1차원 환원).** β개 좌표가 b, α개 좌표가 a인 최소점을 보자. 모멘트가 B 안, A 안에서 대칭이므로 D를 대칭화해도 된다. 그러면 D는 K_B = |T ∩ B|의 법칙으로 정해지고, 조건은 다음 1차원 문제가 된다.
- {L_B, …, U_B} 위에 K_B의 법칙이 있다. 여기서 L_B = max(0, k−α), U_B = min(k, β)이다.
- 그 법칙은 E[K_B] = β(b−s)/(1−s), E[K_B(K_B−1)] = β(β−1)(b²−s)/(1−s)를 만족한다.

정수 구간의 두 모멘트 문제로 쓰면, 이 조건은 다음 두 묶음의 부등식과 같다(E_pi는 주변확률 b인 β개의 쌍별 독립 합 B에 대한 기댓값이다).
- **(II) 정수성:** L_B ≤ j ≤ U_B − 1인 정수 j마다 Ψ_j(s) := E_pi[(B−j)(B−j−1)] − s(β−j)(β−j−1) ≥ 0이다.
  - E_pi[(B−j)(B−j−1)] = β(β−1)b² − 2jβb + j(j+1) ≥ 0이다(곱 법칙이 있으므로).
  - 따라서 이 조건은 s에 대한 상한이다.
- **(I) 지지 끝점:** E_pi[(B−L_B)(U_B−B)] + s(β−L_B)(β−U_B) ≥ 0이다.
  - k ≥ β이면 이 식은 β(1−b)[(β−1)b − L_B] ≥ 0으로 늘 성립한다(L_B = k−α이면 (β−1)b − L_B = α(1−a)).
  - k < β이면 s에 대한 하한이다.

이 식들은 E_D[g(K_B)] = (E_pi[g(B)] − s·g(β))/(1−s)에서 나온다(L에서 B의 법칙은 쌍별 모멘트로 정해지고, R에서는 B ≡ β이다). 또 두 값 경우 R은 동일 주변확률 문제이므로 R–N Theorem 4.1이 덮는다.

따라서 두 값 주변확률에서 추측 C는 "Φ의 근 s가 위 창 안에 있다"로 환원된다. 수치로는 182,726점에서 성립했고, 최소 여유는 α = 1과 k = 1에서 0(항등식으로 성립)이다. 이 창 부등식은 아래 정리 C8에서 증명한다.

**정리 C8 (두 값 주변확률, 새 증명).** p가 많아야 두 가지 값을 가지면 다음이 성립한다.

P̄(n,k,p) = 1 ⇔ p_j < 1인 모든 j에 대해 LOO_j ≥ k

*증명 개요.*
- 보조정리 R의 환원은 두 값 구조를 유지한다. 최댓값이 하나뿐이면 낮춘 뒤 동일 주변확률이 되고, 1인 좌표를 빼도 마찬가지다. 동일 주변확률이면 R–N Theorem 4.1이 적용된다.
- 그래서 β ≥ 2, α ≥ 1, 0 ≤ a < b < 1, (β−1)b + αa = k인 최소점만 보면 된다. k = 1이면 s = b²(Φ(b²) = 0)에서 D가 1-설계가 되므로(§2.1 참고 사항) k ≥ 2라 하자. 그러면 Φ(b²) = (k−1)(1−b)/b > 0이다.
- 표기: m = (β−1)b, x = βb, K_A = αa = k − m.
  - e_j = E_pi[(B−j)(B−j−1)] = (x−j)(x−j−1) + x(1−b)
  - d_j = (β−j)(β−j−1)
  - s_j = e_j/d_j
- 명제 C7에 따라 Φ의 근 s 하나가 W_lo ≤ s ≤ min_j s_j이면 충분하다. 여기서 W_lo는 (I)의 하한(k < β일 때)이다.
- R은 A 위의 동일 주변확률 문제이므로 R–N Theorem 4.1로 존재한다. C1 조건은 C5에서 확인했다.

**보조정리 T1 (부호 전이).** u = b/s, Y = (k−β+u)/α로 두고 다음을 정의한다.

G(u) = b(n−k−u)((α−1)u − (k−β)) − α²(1−a)(b−a)u

그러면 다음 두 항등식이 성립한다.
- f_s(Y) − f_1(a) = G(u)/(α²u)
- f_s(Y) − f_s(y) = (y−Y)((b+s) − s(y+Y))

s ∈ (0, b²]이면 (b+s) − s(y+Y) > 0이다. y ≤ 1이고 Y < b/s이기 때문이다. Y < b/s는 k − β < (α−1)b/s와 같다. k ≤ β이면 자명하고, k > β이면 α ≥ 2이고 (α−1)b/s ≥ (α−1)/b > α−1 ≥ k−β이다. 따라서 s ∈ (0, b²]에서 sign Φ(s) = sign G(b/s)이다.

**보조정리 T2 (근의 구조).** G는 α ≥ 2이면 오목, α = 1이면 기울기 −b(β−k) − α²(1−a)(b−a) < 0인 일차식이다(α = 1이면 k ≤ β). 또 G(1/b) > 0이다(Φ(b²) > 0, k ≥ 2). 따라서 G는 [1/b, u₊)에서 양수, u₊ 뒤에서 음수다.
- u₊ = max{u : G(u) ≥ 0}이라 하면 s* := b/u₊ ∈ (0, b²]는 Φ의 근이다.
- 모든 s₀ ∈ (0, b²]에 대해 s₀ ≥ s* ⇔ G(b/s₀) ≥ 0이다.
- 코드: `general.two_valued_peeling_s`.

**보조정리 T3 (걸리는 첨자).** 다음 항등식이 성립한다.

s_j − s_{j+1} = 2β(1−b)(m−j−1)/((β−j)(β−j−1)(β−j−2))

따라서 min_{j ≤ β−2} s_j는 j* = ⌈m⌉ − 1에서 달성된다. 또 s_0 = b²이다. 그리고 k − α < m이므로 정수 k − α는 j* 이하이고, 따라서 α ≥ k − j*이다.

**보조정리 T4 (위 끝, (II)).** G(b/s_{j*}) ≥ 0이다. 다음 다항식을 쓴다(G(b d_j/e_j)·e_j²/b).

H_j(α) := (e_j(n−k) − b d_j)((α−1)b d_j − (k−β)e_j) − α²(1−a)(b−a)·d_j e_j

H_j는 α에 대해 일차식이다. 증명은 j*의 세 경우로 나눈다.
- **j* = 0:** s_0 = b² ≥ s*이므로 자명하다.
- **j* = k−1 (k < β일 때만 가능):** H_{k−1} = β(α−1)(1−b)²(β−k)(k−1)(m−k)² ≥ 0이다(α ≥ 1).
- **1 ≤ j* ≤ k−2:**
  - α = k−j*에서의 값: H_j(k−j) = β(b−1)(j−β)(j−k+1)(m−j)²((j+1)(1+b) − 2βb)이다.
    - 마지막 인수가 ≤ 0인지 본다. b = m/(β−1)을 넣으면 j+1 ≤ 2βm/(β−1+m)과 같다.
    - 우변은 m에 대해 증가하고, m = j에서 이 부등식은 (j−1)(j−β+1) ≤ 0이 된다. 따라서 1 ≤ j ≤ β−1이면 성립한다.
    - 그러므로 H_{j*}(k−j*) ≥ 0이다.
  - 기울기: H_j = −β(b−1)(αQ₁ + Q₀)라 쓰면 Q₁ = K_A·A₁ + A₀이다.
    - A₁ = (m+β−2j−1)(x(m−2j) + j(j+1)) > 0이다. 이차식 x(m−2j) + j(j+1)의 최솟값이 j(β−1−j)/(β−1) > 0이기 때문이다.
    - A₀ = (m−j)(m−j−1)·[(1+b)(βm + j(j+1)) − 4βbj]이다.
    - j ≤ k−2이면 K_A = k − m ≥ 1이다. 따라서 Q₁ ≥ A₁ + A₀이다.
    - A₁ + A₀ > 0의 증명: j = 1+i, β = j+2+g, m = j+t (i, g ≥ 0, 0 < t ≤ 1)로 두면 (β−1)(A₁ + A₀)는 다음과 같다.

      (i+1)(g+1)[(g+1) − (g+2)t + (g+4)t²] + (g+1)(g+2)t³ + (g+i+3)t⁴

      괄호 안 이차식의 판별식은 −3g² − 16g − 12 < 0이므로 이 값은 양수다.
  - 결론: Q₁ > 0이고 α ≥ k−j*이므로 H_{j*}(α) ≥ H_{j*}(k−j*) ≥ 0이다.
- 따라서 T2에 의해 s* ≤ s_{j*} ≤ s_j(모든 j)이고, (II)가 성립한다.

**보조정리 T5 (아래 끝, k < β에서 (I)).** L = L_B, W_lo = −E_pi[(B−L)(k−B)]/((β−L)(β−k))라 하자. W_lo ≤ 0이면 자명하다.
- W_lo ≤ b²이다. b²(β−L)(β−k) + E_pi[(B−L)(k−B)] = (1−b)(bβ(L+k−1) − Lk(1+b))이기 때문이다. 둘째 인수는 L = 0이면 bβ(k−1) ≥ 0이다. L = k−α이면 b에 대해 일차식이고, b = k/(n−1)에서는 (k−1)(β−k) + α(α−1) ≥ 0, b = 1에서도 ≥ 0이다.
- G(b/W_lo)·W_lo의 분자²/b는 다음과 같다.
  - L = 0일 때: bβ²(b−1)(k−β)(k−1)(m−k)·α(1−a) ≤ 0
  - L = k−α일 때: −bβ(α−1)(b−1)(k−β)(k−n)(m−k)·α(1−a) ≤ 0
  - (m − k = −K_A ≤ 0이다.)
- 그러므로 b/W_lo ≥ 1/b이고 G(b/W_lo) ≤ 0이어서 b/W_lo ≥ u₊, 곧 W_lo ≤ s*이다(T2). ∎

검증:
- 위의 모든 항등식은 sympy로 확인했다(`test_two_valued_sign_transfer_identity`, `test_two_valued_window_identities`).
- 사슬 전체는 `test_two_valued_theorem_float`로 확인했다. 무작위 최소점 1,500개 이상에서 s* = b/u₊가 창 안에 있고, α ≥ k − j*이며, 1차원 LP가 실현 가능함을 본다. 임시 탐색 56,993점(e53)에서도 모두 성립했다.
- 주의: "α를 실수로 풀어 a = b로 완화"한 판본(s ≤ b²/(b + k(1−b)))은 거짓이다. 걸리는 첨자 j*에서 무작위 244,186점 중 2,574점(약 1%)에서 깨졌다(e47). 정수 α ≥ k − j*가 증명의 핵심이다. J20의 경고와 같은 현상이다.

### 2.2 일반 최소점: A로의 환원, B-개수 조건, |A| ≤ 3 (2026-10-30)

**명제 C9 (A로의 환원).** 최소점에서 C5(i)의 k-설계 D가 존재할 필요충분조건은 다음 측도 μ_A가 존재하는 것이다.
- μ_A는 A의 부분집합 위의 확률이다.
- 크기는 max(0, k−β) 이상 min(k, |A|) 이하로 제한된다.
- 1차 모멘트는 π_A, 2차 모멘트는 Π_AA다.

*증명.*
- (⇒) D를 B 안에서 대칭화해도 모멘트는 그대로다. 그 A-주변이 μ_A가 된다.
- (⇐) T_A ~ μ_A를 뽑고, B에서 크기 k − |T_A|인 균등 부분집합을 붙인다. 그러면 B가 들어간 모멘트가 행합 조건과 같아진다.
  - B의 주변확률은 (k − Σπ_A)/β = π_B이다.
  - (B, i) 쌍은 ((k−1)π_i − Σ_{t∈A∖i}Π_it)/β = Π_Bi이다.
  - (B, B) 쌍은 [k(k−1) − 2(k−1)Σπ_A + Σ_{i≠t}Π_it]/(β(β−1)) = Π_BB이다.

  모두 C5의 행합 항등식이다. ∎

μ_A의 모멘트는 (φ(a) − sφ(y))/(1−s)이다. 여기서 φ(v) = (v, vvᵀ)는 주변확률 v인 곱 측도의 모멘트다. 그러므로 μ_A의 존재는 "크기 범위가 있는 상관 다면체" 소속 문제다.

**명제 C10 (B-개수 조건은 모든 최소점에서 성립).** k ≥ 2라 하자.
- (a) u = b/s로 두면 Φ(b/u)는 u에 대해 오목이다. 근거: y = [(1+u) − √((1+u)² − 4cu)]/2이고 c = 1 − (1−a)(b−a)/b이다. 근호 안 이차식의 판별식이 16c(c−1) ≤ 0이므로 근호는 볼록이다.
  - 따라서 Φ의 근 s*는 (0, b²)에서 유일하다. Φ < 0은 (0, s*)에서, Φ ≥ 0은 [s*, b²]에서 성립한다.
  - 이분법(`peeling_parameters`)은 이 근을 찾는다.
- (b) s ≤ b²이면 y_s(a)는 a에 대해 오목이다. y″의 부호는 s(1+b−2a)² − (b+s−2sy)²의 부호와 같다. 그런데 b+s−2sy ≥ b+s−2√s a ≥ √s(1+b−2a)이므로 y″ ≤ 0이다.
- (c) 비교점은 다음 둘이다.
  - 균등 분할: |A|개 좌표가 모두 K_A/|A|인 두 값 점.
  - 극단 꼭짓점: B에 q = ⌊K_A/b⌋개를 더하고 한 좌표만 r = K_A − qb로 둔 두 값 점.

  y_s의 오목성과 Jensen 부등식에서 Σ y_s(a_i)는 균등 분할에서 최대이고, 꼭짓점 q·1 + y_s(r)에서 최소다. 따라서 Φ_균등 ≥ Φ ≥ Φ_극단이고, (a)에 의해 s*_균등 ≤ s* ≤ s*_극단이다.
- (d) 결론: W_lo ≤ s* ≤ min_j s_j이다. 즉 D의 K_B-주변 조건 (I)·(II)가 성립한다.
  - 정리 C8은 균등 분할 점에서 W_lo ≤ s*_균등을 준다(T5).
  - 극단 꼭짓점(두 값, α = 1. r = 0이면 동일 주변확률)에서는 정리 C8로 D_극단이 존재한다. 그 B(β개) 부분 개수는 정수 값이므로 모든 정수 j에서 e_j − s*_극단 d_j ≥ 0이다. 따라서 s*_극단 ≤ min_j s_j이다. ∎

**정리 C11 (|A| ≤ 3, 새 증명).** |A| ≤ 3인 모든 최소점에서 P̄ = 1이다. 따라서 다음이 성립한다.

1인 좌표를 뺀 뒤 두 번째로 큰 값 v₂보다 엄밀히 작은 좌표가 많아야 셋이면, P̄(n,k,p) = 1 ⇔ C1 조건

*증명.* k ≤ 2는 C4이고 k ≥ n−2는 C2이다. 3 ≤ k ≤ n−3이고 |A| ≤ 3이면 k ≤ β이므로, C9의 크기 범위는 [0, |A|], 곧 제한이 없다.

  - (가) 2×2 칸: P3이다.
  - (나) Π_ij + Π_ik − π_i ≤ Π_jk: 곧 s·T_i(y) ≤ T_i(a)이다. 여기서 T_i(v) = v_i(1−v_j)(1−v_k) + (1−v_i)v_jv_k이다. 항별로 성립한다.
    - s·y_i ≤ √s a_i이고 (1−y_j)(1−y_k) ≤ (1−a_j)(1−a_k)이다.
    - s·y_jy_k ≤ a_ja_k(P3)이고 1−y_i ≤ 1−a_i이다.
  - (다) 1 − Σπ + ΣΠ ≥ 0: |T_A| = k − K_B이므로 이 식의 두 배는 E_D[(K_B − k + 2)(K_B − k + 1)]이다. 이는 B-개수 조건 j = k−2와 같고, 명제 C10이 준다. ∎

## 3. 일반적인 필요조건 (BP-최적 법칙이 유일하고 지지가 K일 때)

**정리 E2 (구간 조건).** P̄ = BP이면 다음이 성립한다.
- p_j < 1인 모든 j: min K ≤ LOO_j ≤ max K
- p_j > 0인 모든 j: min K ≤ 1 + LOO_j ≤ max K

특히 0 < p_j < 1이면 min K ≤ LOO_j ≤ max K − 1이다.

*증명.* 보조정리 0으로 극값 법칙은 S ∈ K인 곳에 산다. 그러면 조건부 평균도 [min K, max K]에 있어야 하고, 보조정리 1이 그 값을 준다. ∎ (E1 = C1은 BP=1인 경우의 같은 논법이다.)

**정리 E3 (경직성, K = {0,k,n}, 1 ≤ k ≤ n−1).** P̄ = BP이면, 모든 j에 대해 다음이 성립한다.

p_j(S₁ − p_j − k + 1) = (n−k)v_n,  v_n = (2S₂ − (k−1)S₁)/(n(n−k))

따라서 모든 p_j는 같은 이차방정식 t² − (S₁−k+1)t + (n−k)v_n = 0의 근이다. 결과는 다음과 같다.
- 주변확률이 3개 이상 서로 다른 값을 가지면 BP는 정확하지 않다.
- 서로 다른 값이 두 개 t₁ ≠ t₂이면 t₁ + t₂ = S₁ − k + 1이어야 한다. 이때 곱 조건은 자동으로 따라온다.

*증명.* 층 0에서 X_j(S−1) = 0, 층 n에서 n−1, 층 k에서 (k−1)X_j이다. E[X_j; S=n] = v_n이므로 E[X_j(S−1)] = (n−1)v_n + (k−1)(p_j − v_n)이다. 한편 E[X_j(S−1)] = Σ_{l≠j} p_jp_l = p_j(S₁−p_j)이다. 정리하면 위 식이다. v_n은 BP 지지 {0,k,n}의 모멘트 방정식에서 나온다. j에 대해 합하면 2S₂ − (k−1)S₁ = n(n−k)v_n이 항등식이므로 두 근 조건의 곱 부분은 자동이다. ∎

- 2+3 군(n=5, k=3)에서 서로 다른 두 값 조건은 p + q = 2p + 3q − 2, 즉 **p + 2q = 2**다. 이전에 관찰만 했던 "V10/V11 경계에서 BP가 정확한 예외 곡선"이 바로 이 직선이다(예: (1/2,3/4)에서 M = BP = 23/24).
- 이 직선 위에서도 정확하려면 층 k의 측도(단일 질량 p_i − v_n, 쌍 질량 p_ip_j − v_n)가 실현 가능해야 한다. V15 목격점 (4/11, 9/11)은 직선 위에 있지만 p² = 16/121 < v_5 = 18/121이라 실현 불가능하다(E4).
- 테스트: `test_rigidity_line_in_the_two_three_family`, `test_two_three_pieces_explained_by_criteria`

**명제 G (경직성의 정량판: 경우 (b)에서 BP의 오차 하한).** {0,k,n}(1 ≤ k ≤ n−1)이 BP의 최적 기저라고 하자. 결함을 다음과 같이 정의한다.

Δ_j = p_j(S₁ − p_j − k + 1) − (2S₂ − (k−1)S₁)/n

(E3 조건은 모든 Δ_j = 0과 같고, Σ_j Δ_j = 0이다.) 그러면 다음이 성립한다.

BP − P̄(n,k,p) ≥ max_j |Δ_j| / κ(n,k)

κ(n,k) = max_{s ∉ {0,k,n}} |s−k|·max(s, n−s) / (n·σ(s))
σ(s) = s(n+k−s)/(kn) − 1[s ≥ k]

예: κ(5,3) = 12.

*증명.*
- 지지 {0,k,n}의 쌍대 다항식은 g(s) = s(n+k−s)/(kn)이고(g(0)=0, g(k)=g(n)=1), σ(s) = g(s) − 1[s≥k] ≥ 0은 s ∈ {0,k,n}에서만 0이다.
- 쌍별 독립 법칙 θ에서 E_θ[g(S)] = BP이므로 BP − P_θ(S≥k) = E_θ[σ(S)]이다.
- F_j(x) = x_j(S−k) − S(S−k)/n은 층 0, k, n에서 0이 되는 다중선형 이차식이다. 쌍별 독립이면 E_θ[F_j] = p_j(1 + LOO_j) − kp_j − (S₁ + 2S₂ − kS₁)/n = Δ_j다.
- |S| = s인 x에서 |F_j(x)| ≤ |s−k|·max(1 − s/n, s/n) ≤ κ·σ(s)이므로 |Δ_j| ≤ κ·E_θ[σ(S)]이다.
- θ를 최적으로 잡으면 된다. ∎

**의미.**
- 동일 주변확률 p̄에서 p = p̄**1** + εd로 흔들면 Δ_j ≈ ε·((n−2)p̄ − k + 1)(d_j − d̄)이다. 따라서 (n−2)p̄ ≠ k−1이면 BP의 오차가 **ε에 대해 1차로** 커진다.
- 반대로 정리 L(a)의 비예외 경우에는 작은 ε에서 오차가 0이다. 즉 국소 이분법은 "오차 0 대 오차 Θ(ε)"의 이분법이기도 하다.

**얼마나 잘 맞는가 (탐색, 부동소수점).** F_j들의 일차결합 중 최선의 것으로 같은 논증을 하면 하한이 좋아진다(작은 LP).

**정리 E4 (층 위 법칙, 보조정리 0의 재진술).** P̄ = BP ⇔ ∪_{s∈K} L_s 위의 p의 쌍별 독립 법칙이 존재한다. 그 층들 위의 상태 수가 모멘트 방정식 수와 같고 계가 정칙이면, 해가 유일하므로 음수 성분의 유무로 정확히 판정된다(`general.layered_law_status`).

**정리 E2′ (두 그룹 분할 조건).** [n] = G₁ ⊔ G₂, A = Σ_{G₁} X_i, B = Σ_{G₂} X_i라 하자. 쌍별 독립이면 (A,B)는 다음 다섯 모멘트를 가진다.
- E[A] = Σ_{G₁} p

## 4. SSS 이차항 S₂/C(k,2)의 정확성 — 필요충분조건

**정리 S.** 모든 n ≥ 2, 2 ≤ k ≤ n, p에 대해 P̄(n,k,p) = S₂/C(k,2)일 필요충분조건은 다음 셋이다.
- (I) p_j > 0인 모든 j에 대해 LOO_j ≤ k − 1
- (II) 가중 완전그래프 (p_ip_j)_{i<j}가 분수 K_k-분해를 가진다. 즉 k-부분집합 위의 측도 ρ ≥ 0이 있어 모든 i<j에 대해 Σ_{T ⊇ {i,j}} ρ(T) = p_ip_j이다.
- (III) 1 − S₁ + 2S₂/k ≥ 0

*증명.*
- 정수 s ≥ 0에서 C(s,2)/C(k,2) ≥ 1[s ≥ k]이고, 등호는 s ∈ {0,1,k}일 때만 성립한다. 따라서 S₂/C(k,2)는 항상 상한이고(R–N 식 `SSS`의 둘째 항), 등호는 S ∈ {0,1,k}인 쌍별 독립 법칙이 있을 때와 같다.
- 그런 법칙에서 쌍 확률은 층 k에서만 나온다. 따라서 층 k의 질량 ρ가 (II)를 만족한다.
- 단일 확률은 다음과 같다: P(X = e_i) = p_i − Σ_{T∋i} ρ(T) = p_i − p_i·LOO_i/(k−1). 이것이 ≥ 0인 것이 (I)이다.
- 나머지 질량은 P(X=0) = 1 − S₁ + 2S₂/k이다. 이것이 ≥ 0인 것이 (III)이다.
- 역으로 (I)–(III)이면 위 식으로 법칙을 만들 수 있다. ∎

**따름정리 S2 (k = 2).** P̄(n,2,p) = S₂ ⇔ p_j > 0인 모든 j에 대해 LOO_j ≤ 1이다.
- (II)는 ρ({i,j}) = p_ip_j로 자동 성립한다.
- (III)은 (I)에서 따라온다: 정리 C2(k=n−2)의 P(Y=0) 논법을 p에 그대로 쓰면 된다.

**R–N과의 관계.**
- 동일 주변확률이면 (II)는 균등 ρ로 성립한다. (I)은 k ≥ 1 + (n−1)p, (III)은 k ≤ n(n−1)p²/(np−1)(np > 1일 때)이다. 이것은 R–N Prop. 4.3(b)의 k 구간 [⌈1+(n−1)p⌉, ⌊n(n−1)p²/(np−1)⌋]와 정확히 같다. 따라서 정리 S는 Prop. 4.3(b)를 서로 다른 주변확률로 일반화한다.
- 원래 문제에서 V02 조각(= S₂/3)의 영역은 다음과 같다.
  - q ≤ 2/3 − p/3: p-좌표의 (I)
  - q ≤ 1 − p: q-좌표의 (I)
  - 2p² + 12pq − 6p + 6q² − 9q + 3 ≥ 0: (III)의 3배
  - (II)는 n=5, k=3, p ≤ q에서 항상 성립한다. n=5, k=3에서는 (II)의 해가 유일하다. 쌍과 3-부분집합의 포함행렬이 Petersen 그래프의 인접행렬(고윳값 3, 1, −2)이기 때문이다. 그 해는 ρ(T) = (w(T) + w(T^c) − S₂/3)/2이다. 여기서 w(T)는 T 안 세 쌍의 가중치 합, w(T^c)는 여집합 쌍의 가중치다. (p,p,q,q,q)에서 세 종류 값은 (p²−3pq+3q²)/3, p²/3, p(3q−p)/6이고, p ≤ 3q이면 모두 ≥ 0이다. 궤도 크기를 곱하면 REGIONS.md의 V02 달성분포 π(0,3), π(2,1), π(1,2)와 같다.
- 즉 V02의 facet 부등식은 정리 S의 조건과 정확히 일치한다.
- (II)는 꼭짓점 용량 조건(각 i의 차수 ≤ 전체의 2/k)만으로는 충분하지 않다(탐색: n=5–8에서 반례, J19).
- 테스트: `test_second_moment_term_exactness_float`

## 5. 동일 주변확률 근방의 국소 이분법

**보조정리 L1 (층 합집합의 모멘트 차원, n ≥ 4).** |K| = 3인 K ⊆ {0..n}에 대해, {φ(x) : |x| ∈ K}의 아핀 껍질이 ℝ^{n+C(n,2)} 전체가 아닐 필요충분조건은 다음 둘 중 하나다.
- K = {0, s, n}, 2 ≤ s ≤ n−2. 이때 결손 차원은 n−1이다.
- K ⊆ {0, 1, n−1, n}

*증명.*
- 아핀 껍질이 전체가 아님 ⇔ K의 층들에서 모두 0이 되는 0이 아닌 다중선형 이차식 g가 있음.
- **일반 층(2 ≤ s ≤ n−2) 하나:** 차수 ≤ 2 단항식을 L_s에 제한하면 C(n,2)차원을 생성한다. 이는 포함행렬 W_{2,s}의 rank가 C(n,2)라는 Gottlieb–Kantor–Wilson 정리(t ≤ min(s, n−s)이면 rank W_{t,s} = C(n,t))에서 나온다. L_s 위에서는 x_i = Σ_{j≠i}x_ix_j/(s−1)이므로 일차·상수 단항식이 이차의 생성에 들어 있다. 따라서 L_s에서 0이 되는 g의 공간은 1 + n + C(n,2) − C(n,2) = n+1차원이고, λ(S−s) + Σ_j μ_j x_j(S−s)가 그 전부다.
- **일반 층 두 개 s₁ ≠ s₂:** 두 표현의 x_ix_j 계수를 비교한다(n ≥ 3). 그러면 μ가 같고 상수가 된다. 공통 부분은 g = μ(S−s₁)(S−s₂)(1차원)이다. 셋째 층 t ∉ {s₁,s₂}에서 g = μ(t−s₁)(t−s₂)이므로 μ = 0이다. 따라서 일반 층이 둘 이상이면 껍질이 꽉 찬다.
- **일반 층 하나 s + 특수 층 둘({0,1,n−1,n} 중):** g = λ(S−s) + Σμ_jx_j(S−s)를 특수 층에서 계산하면 다음과 같다.
  - L₀: −λs
  - L_n: (n−s)(λ + Σμ)
  - L₁(x=e_j): (1−s)(λ+μ_j)
  - L_{n−1}(x=1−e_j): (n−1−s)(λ + Σ_{l≠j}μ_l)

  여섯 쌍을 각각 풀면 {0,n}만 해가 남는다(λ=0, Σμ=0: n−1차원). 나머지는 g=0이다.
- **특수 층만:** 0이 아닌 g가 직접 존재한다. 예: {0,1,n}에서 Σ b_ij x_ix_j (Σ b_ij = 0)
- 계산 확인: n=4–7의 모든 K(`test_layer_kernel_classification`, 정확 rank)와 n=8(J19). ∎

**정리 L (국소 이분법).** n ≥ 4, 0 < p̄ < 1이라 하자. 동일 주변확률 p̄·**1**에서 BP 문제가 지지 K(|K|=3)의 최적 기저 법칙 v̄ > 0을 가진다고 하자.
- (a) K가 L1의 예외가 아니면, p̄·**1**의 근방 U가 있어 모든 p ∈ U에서 P̄(n,k,p) = BP(p)이다. 즉 서로 다른 주변확률의 **열린 집합**에서 BP가 정확하다.
- (b) K가 예외이고 그 쌍대해가 엄밀 상보적(K 밖에서 쌍대 여유 > 0)이면, U 안에서 BP가 정확한 점은 진부분 대수다양체 {p : φ(p) ∈ aff φ(L_K)}에 들어간다(내부가 없다). K = {0,k,n}이면 이것은 E3의 경직성 조건이다.

*증명.*
- (a) 교환가능 법칙(각 층 안에서 균등, 층 질량 v̄)의 모멘트 점 φ(p̄**1**)은 K-층 모든 상태의 φ를 양의 가중치로 결합한 것이다. 아핀 껍질이 전체이므로 이 점은 볼록껍질의 내부에 있다. φ의 연속성으로 p가 가까우면 φ(p)도 내부에 있어서, K-층 위의 p의 쌍별 독립 법칙이 있다. 그 S-법칙은 K 위에서 유일한 모멘트 해 v(p)이고 p̄ 근처에서 v(p) > 0이다. 기저 K의 쌍대 실행가능성은 우변과 무관하므로 v(p)는 BP-최적이다. 보조정리 0으로 결론이 나온다.
- (b) 쌍대해 y_K는 U에서도 최적이다(v(p) ≥ 0). 엄밀 상보성으로 모든 BP-최적 법칙은 K 위에 산다. 따라서 P̄ = BP이면 φ(p)가 K-층 상태들의 볼록결합이다. φ(p) ∈ aff이라는 조건은 p의 0이 아닌 다항식(단항식 1, p_i, p_ip_j가 일차독립)의 영점집합이다. ∎

**R–N Theorem 4.1의 세 경우에 대입 (n ≥ 4).**
- **(a)** K = {j−1, j, n}(BP=1): 예외가 아니다. 동일 주변확률 근방에서 P̄ = 1이 안정적이다(이 경우 BP-최적 법칙은 유일하지 않지만 (a)의 논증은 그대로 된다).
- **(b)** K = {0,k,n}: **항상 예외다.** 동일 주변확률에서의 tightness는 섭동에 약하다. 서로 다른 값이 셋 이상이면 BP는 깨진다(E3).
- **(c)** K = {i−1, i, k}: 예외는 i = 1이고 k ∈ {n−1, n}일 때뿐이다. 그 경우 {0,1,n}에서는 쌍 질량이 모두 층 n에서 오므로 p_ip_j가 모두 같아야 하고, 사실상 동일 주변확률만 허용된다.

**원래 문제(n=5, k=3)에 대입.** 대각선 p=q는 다음 순서로 세 경우를 지난다.
- p ≤ 1/2: (c) {0,1,3} → 정리 L(a)로 대각선 양쪽에 열린 BP-정확 조각이 있다(V02).
- 1/2 ≤ p ≤ 3/4: (b) {0,3,5} → 정리 L(b)로 대각선에서만 정확하다. 실제로 V10, V11이 대각선에서 만나고 BP는 거기서만 정확하다(따름정리 C의 Z).
- p ≥ 3/4: (a) → 열린 조각(V18)

즉 따름정리 C(i)에서 BP가 정확한 조각이 왜 V02, V18처럼 대각선을 끼고 있는지, 그리고 왜 중간 구간에서는 대각선에서만 정확한지가 정리 L로 설명된다. V16은 대각선에 닿지 않는 (c) {1,2,3} 조각으로, 정리 L이 아니라 E2와 실제 법칙으로 확인된다.

## 6. 순서 기반 상한 (R–N Theorem 3.1(b))

**정리 E5.** OBP = min_r BP_r라 하자. BP_r은 가장 작은 n−r개 주변확률 p_B에 대한 임계값 k−r의 BP다. P̄ = OBP이고 r*가 최소를 달성하면 다음 둘이 성립한다.
- (i) P̄(n−r*, k−r*, p_B) = BP_{r*}
- (ii) 최적 법칙에서 {S ≥ k} = {S_B ≥ k−r*}가 거의 확실하게 성립한다.

따라서 E1–E4를 (p_B, k−r*)에 적용할 수 있다. 특히 OBP = 1이면 전체 p에 E1을 적용한다.

*증명.* 최적 θ에서 P_θ(S≥k) ≤ P_θ(S_B ≥ k−r*) ≤ BP_{r*} = P_θ(S≥k)이다. θ를 B에 제한하면 p_B의 쌍별 독립 법칙이다. ∎
