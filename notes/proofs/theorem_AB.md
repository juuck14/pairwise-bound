# 정리 A·B와 따름정리 C: M(p,q)의 정확한 조각 분류

상태: **컴퓨터 보조 증명**.
- 논증의 뼈대는 표준 LP 이론으로 사람이 확인할 수 있다.
- 유한 계산 부분(쌍대 꼭짓점 열거, 목격점, 지배 덮개, facet, 다항식 항등식)은 독립 검증기가 정확한 유리수 계산으로 확인한다. 검증기는 표준 라이브러리만 쓰고 생성 코드와 분리되어 있다.
  - 증서: `results/regions/region_certificate.json`
  - 검사: `python -I verifier/verify.py results/regions/region_certificate.json` → 54개 검사 PASS
- 조각별 공식과 부등식: `results/regions/REGIONS.md`(생성 파일)
- 그림: `results/regions/region_map.png`(예시용이며 증거가 아님)

표기는 `notes/proofs/reduction.md`와 같다. 정리 R에 의해 M(p,q)는 12상태 LP의 최적값이다.

max c·π  s.t.  Aπ = b(p,q), π ≥ 0
- A: 열 r(a,b) = (1, a, b, a(a−1), b(b−1), ab)
- b(p,q) = (1, 2p, 3q, 2p², 6q², 6pq)
- c(a,b) = 1[a+b≥3]

쌍대 실행가능 집합은 𝒟 = {y ∈ ℝ⁶ : y·r(a,b) ≥ c(a,b), 12점 모두}이고, Q_y(p,q) := y·b(p,q)이다.

---

## 정리 A (유한 포락선)

모든 (p,q) ∈ [0,1]²에 대해 다음이 성립한다.

M(p,q) = min_{y ∈ V} Q_y(p,q)

V는 𝒟의 꼭짓점 집합이며 정확히 21개다. 각 Q_y는 (p,q)의 2차 이하 다항식이다.

**증명.**
1. **원문제의 실행가능성과 유계성.** 곱분포 Bin(2,p)×Bin(3,q)는 항상 실행 가능하다. 검증기 `RG_FEASIBLE`이 Aπ ≡ b(p,q)를 다항식 항등식으로 확인한다. 목적은 ≤ 1이다.
2. **강쌍대성.** 1에 의해 M(p,q) = min_{y∈𝒟} b(p,q)·y이다.
3. **pointed.** rank A = 6이다(`RG_RANK`). 따라서 𝒟의 선형성 공간 {y : Aᵀy = 0} = {0}이고 𝒟는 pointed다. 아래로 유계인 선형함수는 pointed 다면체의 꼭짓점에서 최솟값을 가진다.
4. **꼭짓점의 열거.** y가 𝒟의 꼭짓점일 필요충분조건은, tight 제약 중 선형독립인 6개가 있는 것이다. 이는 다음과 같이 말할 수 있다.
   - A_B가 정칙인 6열 집합 B가 있고
   - A_Bᵀ y = c_B를 만족한다.
   - 따라서 V는 C(12,6) = 924개 부분집합을 모두 열거해 얻는 쌍대 실행가능 기저해 집합과 같다.
   - 열거 결과: 정칙 764, 쌍대 실행가능 50, 서로 다른 해 21.
   - 검증기 `RG_VERTICES`가 자기 코드로 다시 열거해 증서의 목록과 대조한다.
5. 2–4에서 결론이 나온다. ∎

## 정리 B (조각 분류)

D = {0 ≤ p ≤ q ≤ 1}이다. 각 y∈V에 대해 R_y = {(p,q) ∈ D : M(p,q) = Q_y(p,q)}라 하자.

**(i) 내부 활성 조각은 정확히 11개다.** 다음 11개에 대해 R_y는 내부점을 가진다.

V02, V10, V11, V12, V14, V15, V16, V18, V19, V20, V21

나머지 10개(V01, V03, V04, V05, V06, V07, V08, V09, V13, V17)에 대해 R_y는 D 안에서 내부가 없다.

**(ii) 영역 기술.** 각 y에 대해 T_y = {s : y·r(s) = c(s)}이다. 그러면 다음이 성립한다.

R_y = {(p,q) ∈ D : b(p,q) ∈ cone{r(s) : s ∈ T_y}} = {(p,q) ∈ D : h·b(p,q) ≥ 0, ∀ facet 법선 h}

각 h·b(p,q)는 (p,q)의 2차 이하 다항식이다. 11개 조각의 부등식 목록은 `REGIONS.md`에 있다.

**(iii) 달성분포.** 각 조각의 기저 B마다 x_B(p,q) = A_B⁻¹b(p,q)는 성분이 (p,q)의 다항식이다. x_B(p,q) ≥ 0인 점에서 x_B는 12상태 최대화 분포다. 이를 32상태로 복원한 것(정리 R)은 원문제의 최대화 분포다.
- 비퇴화 조각(T_y가 6개)에서는 {x_B ≥ 0} = R_y이다. 즉 하나의 다항식 공식이 영역 전체에서 유효하다.
- 퇴화 조각 V16(T 8개, 기저 25개)에서는 tight 상태 위의 비음수 해가 모두 최대화 분포다. 증서에는 D 내부에서 쓰이는 기저 7개를 실었다.

**증명.**
- **(i) 활성.** 증서의 목격점 w_y는 0<p<q<1을 만족하는 유리수 점이다. `RG_ACTIVE_*`는 w_y에서 Q_y < Q_{y'}(모든 y' ≠ y)임을 정확히 확인한다. 연속성에 의해 w_y의 근방에서도 같은 부등식이 성립하므로, 근방이 R_y에 포함된다.
- **(i) 비활성.** 덮개 트리는 D를 중점 분할한 삼각형들로 덮는다. 각 잎 삼각형 Δ에서 min_Δ(Q_y − Q_{y'}) ≥ 0인 y' ≠ y가 있다(`RG_INACTIVE_*`, 삼각형 위 이차식 최솟값의 정확 계산: SPEC §8.4). 따라서 D의 어느 점에서도 y는 유일 최소가 아니다.
  - 귀류법으로 R_y가 열린 집합 U를 포함한다고 하자. y ≠ y'이면 Q_y ≠ Q_{y'}이다. 사상 y ↦ Q_y가 단사이기 때문이다(계수 y0, 2y1, 3y2, 2y3, 6y4, 6y5).
  - 따라서 {Q_y = Q_{y'}}는 내부가 없는 닫힌 집합이다. 유한개의 그런 집합의 합집합을 U에서 빼도 공집합이 아니다.
  - 그 점에서 y는 유일 최소가 되어 모순이다.
- **(ii) 첫 등호.** y∈V는 쌍대 실행가능하다. 따라서 y가 (p,q)에서 쌍대 최적인 것은, 상보여유성에 의해 T_y 위에만 지지되는 원문제 실행가능해가 있는 것과 같다. 이는 b(p,q) ∈ cone(r(T_y))와 같다.
- **(ii) 둘째 등호.** r(T_y)의 rank는 6이다(꼭짓점이므로). 따라서 원뿔은 완전 차원이고 facet 반공간들의 교집합이다. 첫 좌표가 모두 1이므로 pointed이기도 하다.
  - 각 facet은 생성원 5개로 펼쳐진다. 그래서 5-부분집합 열거로 facet을 모두 찾는다.
  - `RG_REGION_*`가 tight 집합, rank, facet 목록을 독립적으로 다시 계산해 대조한다.
  - "D에서 자명"으로 표시한 facet은 D 위의 정확한 최솟값 ≥ 0으로 확인한다.
- **(iii)** `RG_MAXIMIZER_*`가 다음 두 항등식을 확인한다.
  - A·x_B ≡ b(p,q)
  - c·x_B ≡ Q_y
  - x_B ≥ 0이면 x_B는 실행 가능하고, 목적값이 Q_y ≥ M(약쌍대성)이므로 최적이다.
  - 비퇴화일 때 x_B의 각 성분은 facet 다항식의 양의 배수다(검증기 확인). 그래서 {x_B ≥ 0} = R_y이다. ∎

## 따름정리 C (선행 상한의 tightness)

다음 세 상한을 생각한다.
- **두 모멘트 상한 BP(p,q):** S의 이항모멘트 S₁, S₂만 쓰는 Boros–Prékopa 상한. Ramachandra–Natarajan(R–N, arXiv:2006.00516 v6) §1의 식이다.
- **순서 기반 상한 OBP(p,q):** R–N Theorem 3.1(b). §3.2의 Theorem 2.3 강화를 포함한다.
- **기타:** R–N Theorem 3.1(a)(c)의 ordered SSS·Chebyshev 상한. 둘 다 OBP 이상이다(R–N §3.1).

D에서 이 상한들이 M과 같아지는 점의 집합은 다음과 같다. Z는 내부가 없는 집합(유한개 대수 곡선의 부분집합)이다.

R_V02 ∪ R_V16 ∪ R_V18 ∪ Z

따라서 나머지 8개 조각(V10, V11, V12, V14, V15, V19, V20, V21)의 내부에서는, Z를 뺀 열린 조밀 부분집합 위에서 이 상한들이 **엄밀히 느슨하다**. 예를 들어 대표점(V12 내부)에서 BP = OBP = 107/125 > 61/75 = M이다.

**증명.**
1. **상한을 쌍대점의 최솟값으로 쓴다.** OBP의 각 항(r = 0,1,2)은 가장 작은 n−r개 변수 합에 대한 이항모멘트 LP다. p≤q이면 그 변수들은 X1, X2, X3, …이다. 이 LP의 쌍대 꼭짓점 g는 다음 과정을 거쳐 12상태 쌍대 실행가능점 w가 된다.
   - g(x_1+…+x_{n−r})는 32상태 쌍대로서 실행 가능하다. S≥3이면 부분합 ≥ 3−r이기 때문이다.
   - 이를 S₂×S₃로 평균하면 실행가능성과 값이 유지된다(명제 D).
   - §3.2 항도 R–N Theorem 2.3의 쌍대를 같은 방법으로 옮긴다.
   - 그러면 유한집합 W에 대해 OBP = min_{w∈W} Q_w이다. W의 원소는 8개다.
   - BP는 r=0 항만 쓰므로 W의 부분집합 위의 최솟값이다.
   - 확인: `tests/test_rn_bounds.py::test_bound_is_minimum_over_finite_dual_set`. 닫힌꼴과 모멘트 LP의 일치는 `test_closed_form_matches_moment_lp_and_bounds_are_valid`에서 확인한다.
2. **tight 조건을 원뿔 소속으로 바꾼다.** OBP(p,q) = M(p,q)일 필요충분조건은 어떤 w∈W가 (p,q)에서 쌍대 최적인 것이다. 정리 B(ii)와 같은 논법으로 이는 b(p,q) ∈ cone(r(T_w))와 같다.
3. **rank로 갈라 본다.** W 중 r(T_w)의 rank가 6인 것은 V02, V16, V18뿐이다(`test_only_sum_only_vertices_carry_full_rank`).
   - 나머지 w는 rank ≤ 5다. 그러면 cone(r(T_w))는 어떤 초평면 {h·v = 0}에 들어 있다.
   - 따라서 그 w가 최적인 점은 곡선 h·b(p,q) = 0 위에 있다. h·b(p,q)는 0이 아닌 다항식인데, 1, p, q, p², q², pq가 일차독립이기 때문이다.
4. 2와 3에서 결론이 나온다. ∎

**참고.**
- W 원소 중 하나 z = (0, 7/15, −2/15)의 12상태 상은 (3/5)·y_V10 + (2/5)·y_V11이다(계획 단계 손계산, 코드로 확인함). 이 점이 최적인 곳은 R_V10 ∩ R_V11이다.
- 그 안에는 대각선 구간 p=q∈[1/2,3/4]가 있다. 여기서 BP가 tight한 것은 R–N Theorem 4.1(b)와 일치한다.

## 대각선과 경계 (재현)

- **p=q:** 12상태 값이 R–N Theorem 4.1의 닫힌꼴과 같다(p=k/97, `test_theorem_4_1_reproduced_on_the_diagonal`). 해당 조각은 다음과 같다.

## 한계와 남은 일

- "내부가 없는 집합 Z"의 정확한 기술(어느 곡선 조각인지)은 하지 않았다.
- 조각 경계의 교점은 `results/regions/JUNCTIONS.md`에 있다(claims C11).
  - 좌표는 sympy 정확해이고, 표에 적힌 조각들이 그 점에서 M을 정확히 달성함을 테스트로 확인했다.
  - 다만 교점 목록이 빠짐없는지와 어느 조각이 맞닿는지는 수치 표본으로 판정했다. 그래서 이 표는 정리 B의 일부가 아니다.
- p>q 영역은 연구 범위 밖이다. 정리 A는 [0,1]² 전체에서 성립하지만, 정리 B의 분류는 D에서만 했다.
