## 1. 무엇이 반복되었나

1차 재평가에서 질문을 "BP는 언제 정확한가(일반 n, k)"로 바꿨다. 그런데 그 안에서 "추측 C(P̄ = 1 판정)의 증명"이 1순위가 되었고, 그 뒤 세 세션 동안 같은 패턴이 반복되었다.

| 날짜 | 결과 | 실제 성격 |
|---|---|---|
| 10/30 | 정리 C4 (k = 2) | 벗겨내기 구성 L = (1−s)D + sR. 새 구성이다 |
| 10/30 | 정리 C8 (두 값 주변확률) | 같은 구성 + 1차원 창 부등식(인수분해) |
| 10/30 | 정리 C11 (\|A\| ≤ 3), 보조정리 C12 | 같은 구성 + 비교점(오목성, Jensen) |
| 11/14 | 보조정리 C12′, 정리 C13 (n ≤ 6) | C12 논법의 재적용 + 컴퓨터 면 열거 |

- 첫 단계(벗겨내기) 뒤의 단계들은 사례를 하나씩 넓혔다. 넓힐 때마다 이전 논법을 다시 썼다.
- 특히 C13은 면 열거(계산)에 의존한다. 상관 다면체 COR(m)은 공분산 사상으로 cut 다면체 CUT(m+1)과 같고, 일반 m에서 면 목록은 알려져 있지 않다. 실제로 \|A\| = 5에서 새 면 유형(경로형, 5-순환형)이 나왔다(J27 e65). 그러니 이 경로는 일반 n으로 가지 않는다.
- 추측 D(벗겨내기 설계의 존재)는 "1·2차 포함확률이 주어진 고정 크기 표본설계의 존재"다. 이것은 표본조사론에서 따로 연구된 문제다(Gabler–Schweigkoffer 1990, Metrika, "The existence of sampling designs with preassigned inclusion probabilities"; Taga 1993). 서지와 검색 요약만 확인했고 원문은 이 세션에서 접근하지 못했다(§5). 일반 해가 어렵다는 신호로 읽어야 했다.

### 원인
1. **인계 문서가 "다음 사례"를 1순위로 고정했다.** HANDOFF의 "다음 행동"이 "n = 6, k = 3을 끝내기", "그다음 \|A\| = 4의 다른 범위"처럼 사례 단위였다. 세션마다 그 목록의 국소 진전을 최적화했다.
2. **기여 판정 관문이 없었다.** "무엇이 새 아이디어인가, 일반 n으로 가는가, 문헌에 있는가"를 확인하지 않고 "새 증명", "새 결과"라고 표기했다.
3. **문헌 확인을 미룬 채 진행했다.** 핵심 문헌(Boros–Prékopa 1989 등)이 차단되어 있다는 이유로 신규성 판단을 보류하고 결과를 쌓았다.
4. **원 논문이 명시한 열린 문제를 기준점으로 쓰지 않았다.** R–N(arXiv:2006.00516 v6) 결론 절은 열린 문제 두 개를 적었다. (a) k ≥ 2에서 P̄(n,k,p)를 효율적으로 계산(또는 근사)할 수 있는가, (b) 4/3 추측(상관 격차)이다. (b)는 이미 다른 사람들이 다뤘다(arXiv 2606.19663, 2609.02659). (a)는 1차 재평가에서 "위험이 크고 빠른 판별 실험이 없어 보류"로 처리하고 다시 보지 않았다.

## 3. 기여 판정 기준 (앞으로 모든 주장에 적용)

어떤 결과를 "기여"라고 적으려면 다음 넷을 모두 적는다. 하나라도 비면 "계산" 또는 "재적용"으로 분류한다.

- **G1 일반성:** 일반 n(또는 무한 족)에 대한 진술인가? 사례·유한 열거에 의존하면 그것을 명시한다.
- **G2 새 단계:** 가장 가까운 기존 결과(문헌 또는 이 프로젝트의 이전 논법)를 대입하면 어디까지 나오는가? 그 뒤에 새로 필요했던 단계는 무엇인가?
- **G3 질문의 출처:** 문헌이 묻거나 열어 둔 질문에 답하는가? 아니면 우리가 만든 질문인가?
- **G4 문헌 범위:** 무엇을 원문으로 확인했고 무엇을 못 했는가?

또 인계 문서의 "다음 행동" 1순위는 사례 단위로 쓰지 않는다. 일반 진술 단위로 쓰고, 사례는 그 진술의 시험으로만 쓴다.

### 4.1 후보 B의 빠른 판별 (scratchpad e67–e72, 고정 시드)
- e67–e69: P̄(n,2,p)의 쌍대 LP 최적해(이차 증서 q(x) ≥ 1[|x| ≥ 2])는 모두 반정수 계수였다. 서로 다른 유형은 n = 5에서 17개, n = 6에서 13개, n = 7에서 8개로 늘지 않았다.
  - 대표 유형 1: KHW(k = 1의 tight 상한)를 최댓값 좌표를 뺀 나머지에 적용한 것. R–N의 순서 기반 상한(§3.2 강화판)에 들어 있다.
  - 대표 유형 2: p_c + (1−p_c)·LOO_c/2. 조건부 평균에 Markov 부등식을 쓴 것이다.
  - 대표 유형 3: 정렬된 좌표를 (아래 묶음 R, 축 c, 위 묶음 T)로 나눈 군별 대칭 이차식. 예: 2N_R − N_R·N_T + C(N_T, 2).
- e70: 관찰을 가설로 바꿨다. **정렬 순서에서 연속인 많아야 4개 묶음으로 집계한 LP의 최솟값이 P̄(n,2,p)와 같다.**
  - 집계 LP: 묶음별 개수 (N_1, …, N_g)의 법칙 위에서 E N_a = P_a, E C(N_a,2) = e₂(p_{G_a}), E N_aN_b = P_aP_b(쌍별 독립에서 정해지는 값)를 주고 P(Σ N ≥ k)를 최대화한다.
  - 모든 분할의 집계 LP는 P̄의 상한이다(이완이므로).
  - 결과: n = 5, 6, 7, 8 무작위 610점에서 4개 묶음이면 오차 ≤ 3·10⁻¹⁵였다. 3개 묶음이면 최대 1.7·10⁻³ 차이가 났다.
- e71: k = 1은 2개 묶음(축 + 나머지)으로 정확했다. 이는 R–N Theorem 2.3(KHW)과 일치한다. k = 3, 4는 n ≤ 8에서 5개 묶음이 필요했다(무작위, 표본이 적다).
- e72: n = 5–7에서 4개 묶음 가설을 깨려는 적대적 탐색(언덕 오르기, 동률 유도, 75회)을 했다. 최대 차이는 1.3·10⁻¹⁵였다.
- e73–e74: "큰 묶음 하나 + 홑원소 3개 이하"로 줄이는 강화 가설은 거짓이었다. P̄ < 1인 점에서 n = 8일 때 최대 차이가 6·10⁻³이었다. e73에서 그렇게 보인 것은 P̄ = 1인 점이 표본을 채웠기 때문이다.
- e75: 최적 집계 법칙은 큰 묶음의 개수 m에 대해, 아핀 포함확률이 [0,1]을 벗어나는 m에도 질량을 둔다. 그래서 "아핀 포함확률로 분해"하는 단순 경로는 그대로는 쓸 수 없다.
- e76: P̄ < 1인 점만 따로 보았다. 4개 묶음의 최대 차이는 n = 5, 6, 7, 9에서 ≤ 1.4·10⁻¹⁵였다. **n = 8에서는 한 점에서 2.8·10⁻⁶였다.**
- e77–e78: 그 점 p = (0.0055, 0.0108, 0.0318, 0.034, 0.0647, 0.3735, 0.3831, 0.5845)을 유리수로 정확히 확인했다.
  - 반정수 쌍대 증서로 P̄ ≤ 0.68418893이다.
  - 연속 4-묶음 분할 전부에서 집계 LP의 정확한 실행 가능 법칙이 0.684191845 이상의 값을 가진다.
  - **따라서 가설 H(k=2, 4개 묶음)는 거짓이다.** 이 점에서는 5개 묶음(크기 1, 1, 2, 1, 3)이면 정확하다. 테스트는 `tests/test_aggregation.py::test_k2_four_groups_fail_at_n8_exact`다.
- e79: n = 8에서 5개 묶음을 깨려는 적대적 탐색(6회)에서 최대 차이는 3.6·10⁻¹⁵였다. n = 9는 시작점이 모두 P̄ = 1이라 탐색이 되지 않았다(설계 실패, 다시 해야 한다).

**현재 판단(2026-11-14 세션 끝).**
- "고정된 작은 개수의 연속 묶음이면 정확하다"는 가설은 4개에서 깨졌다.
- 필요한 묶음 수가 n과 함께 자라는지는 모른다.
- 자라지 않으면(예: 5개, 또는 k에만 의존) 다항식 시간 결론이 살아난다.
- 자란다면 집계 경로로는 R–N (a)에 답할 수 없다. 그때는 쌍대 증서의 유한 족(e67–e69의 반정수 유형) 쪽으로 옮기거나, 후보 D(난해성)를 다시 평가한다.
- 이 판단 전까지 후보 B에서 "기여"라고 적을 수 있는 결과는 없다. 지금 있는 것은 다음 둘뿐이다.
  - 탐색 결과(집계가 작은 n에서 정확함)
  - 가설 하나의 정확한 반례

### 4.2 B의 위험과 중단 기준
- 위험 1: 가설이 드문 점에서 깨질 수 있다. 적대적 탐색으로 반례가 나오면 그 점의 구조를 기록하고, 필요한 묶음 수가 n과 함께 자라는지 본다. 자란다면 "고정 개수 묶음"으로는 다항식 시간 결론이 나오지 않으므로 다시 평가한다.
- 위험 2: 증명이 어렵다. 집계 법칙을 쌍별 독립 법칙으로 되돌리는(분해) 단계는 추측 D와 같은 종류의 어려움을 가질 수 있다. 쌍대 쪽(최적 증서가 묶음별 대칭이 되게 하는 교환 논법)도 함께 시도한다.
- 위험 3: 집계 LP와 Prékopa 계열의 "부분 집계" 문헌(Prékopa–Gao 2005, Qiu–Ahmed–Dey 2016)에 같은 관찰이 있을 수 있다. 다만 R–N 2022 결론이 k ≥ 2의 계산 가능성을 열린 문제로 적었으므로, 적어도 쌍별 독립 + 서로 다른 주변확률에 대한 답은 R–N 시점에 알려지지 않았다. 이 문헌 원문은 여전히 확인하지 못했다.
