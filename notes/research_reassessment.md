## 2. 오류 정정: claims C9 (따름정리 C의 SSS·Chebyshev 확장)

손계산, (p,q) = (1/7, 4/7), 오름차순 (1/7, 1/7, 4/7, 4/7, 4/7), k = 3.

**r = 0**
- S₁ = 2/7 + 12/7 = 2, S₂ = p² + 6pq + 3q² = (1 + 24 + 48)/49 = 73/49
- BP: (n−1)S₁ − 2S₂ = 8 − 146/49 = 246/49이므로 첫 경계는 (246/49)/3 = 82/49 < 3이다. 둘째 경계는 1 + 2S₂/S₁ = 122/49 < 3이다. 따라서 셋째 경우다. i = ⌈(2·2 − 146/49)/(3−2)⌉ = ⌈50/49⌉ = 2이고, 상한 = ((1)(2−4) + 146/49)/(1+1) = **24/49** (지지 {1,2,3})이다.
- SSS 항: S₁/3 = 2/3, S₂/3 = **73/147**
- Chebyshev 항: var = Σp_i(1−p_i) = 2·6/49 + 3·12/49 = 48/49, (k−S₁)² = 1이므로 **48/97**

**r = 1** (p,p,q,q)
- S₁ = 10/7, S₂ = (1 + 16 + 16)/49 = 33/49
- SSS 항: 5/7, 33/49
- Chebyshev: var = 36/49, (2 − 10/7)² = 16/49 → 9/13

**r = 2** (p,p,q)
- S₁ = 6/7
- SSS 항: 6/7
- Chebyshev: var = 24/49, (1/7)² = 1/49 → 24/25

**§3.2 강화 항:** 2p + q − 2pq = 34/49

**결과**
- M = 1 − S₁ + S₂ = 24/49 (조각 V16)
- 순서 기반 BP(강화판) = 24/49 = M
- 순서 기반 SSS(강화판) = min(1, 2/3, 73/147, 5/7, 33/49, 6/7, 34/49) = **73/147 > 24/49**
- 순서 기반 Chebyshev(강화판) = min(1, 48/97, 9/13, 24/25, 34/49) = **48/97 > 24/49**

사람이 제시한 네 값이 모두 맞다. 따라서 "BP가 정확한 영역에서 SSS·Chebyshev도 정확하다"는 이전 서술은 틀렸다.
- 원인: 원래 증명은 OBP의 tight 집합만 다뤘다. SSS·Chebyshev ≥ OBP에서는 포함 관계(⊆)만 나오는데 등호로 썼다.
- 정정한 진술(증명 포함): BP형 R_V02 ∪ R_V16 ∪ R_V18 ∪ Z, SSS형 R_V02 ∪ R_V18 ∪ Z′, Chebyshev형 R_V18 ∪ Z″ (`notes/proofs/theorem_AB.md` 따름정리 C, `tests/test_rn_bounds.py`).
- 고친 문서: theorem_AB, claims, README, SUBMISSION, literature, presentation_content (커밋 be7b75d).

## 4. 후보 연구 질문 (성격이 다른 5개 + 제외 1개)

### Q1. 구조·필요충분조건: BP형 상한은 서로 다른 주변확률에서 언제 정확한가?
- **무엇이 궁금한가:** P̄(n,k,p) = BP(S₁,S₂)가 되는 p의 집합과, 정확하지 않을 때 그것을 막는 원인
- **왜:** R–N은 동일 주변확률과 특수 사례에서만 tight함을 보였다. Example 3.2의 tight 사례는 설명 없이 남아 있다. 우리 2+3 계산도 "3개 조각에서만 정확"이라는 사실만 줬다.
- **기존 연구 범위:** Thm 4.1(동일), Prop. 4.3(동일, SSS·Chebyshev), Prop. 4.5(n−1+1)
- **필요한 단계:** 층 기준(LP)을 넘어 쌍별 독립 구조를 실제로 쓰는 장애·구성 논증
- **성공하면:** 일반 n, k에서 정확성 판정. 기존 tight 사례 전부의 설명. 2+3 조각 구조의 원리
- **위험:** 층 기준 자체는 상보여유성의 재진술이라 자명하다. 결과가 "LP를 풀어 보라"로 끝날 위험이 있다
- **빠른 판별(실제 수행):**
  - 무작위 사례 n=4–7에서 경우별 정확성 조사(J19)
  - Example 3.2 재현과 경우 판정: 24칸이 세 장애로 갈림
  - 층 합집합 차원 계산 n ≤ 8: 깨끗한 분류
  - **유망하다고 판단**

### Q2. 닫힌꼴: k = 2의 정확한 tight 상한(임의 p)
- **무엇이 궁금한가:** R–N이 k=1을 닫힌꼴로 푼 다음 단계
- **필요한 단계:** 쌍대 해 구조의 일반 공식
- **빠른 판별(수행):** n=3은 P̄ = S₂ − 2 max(0, max_j p_j(LOO_j − 1))로 풀린다. n ≥ 4에서는 단순 후보식 두 개가 틀렸다(J19). 구조가 복잡해 보인다
- **부분 결과:** Q1의 정리 S에서 "P̄(n,2,p) = S₂ ⇔ max LOO ≤ 1"이 나온다
- **위험:** 전체 닫힌꼴은 이 세션에서 어려움

### Q3. 극값 비교(Hoeffding형): 평균을 고정하면 동일 주변확률이 최악인가?
- **필요한 단계·위험:** 볼록 경우(c)에서는 BP의 S₂-단조성과 Thm 4.1로 거의 바로 따라온다(자명할 위험). 평균 근처에서는 (p,q)→(0,1)처럼 이질성이 값을 키우는 자명한 예가 있다
- **빠른 판별:** 손계산 두 점(M(2/5,3/5)=0.813 < 동일 0.853, M(3/5,2/5)=0.76 < 0.768)과 논증만. **설명력이 낮다고 판단해 보류**

## 5. 선택과 이유

**Q1을 주 질문으로, Q2를 Q1에서 나오는 범위만큼(k=2 정확성 영역) 다루기로 했다.**

- Q2의 전체 닫힌꼴은 이번 세션 안에 성공 가능성이 낮다고 판단했다.

- R–N은 "서로 다른 주변확률에서 기존·새 상한은 일반적으로 tight하지 않고, 특수 사례에서 tight하다"고만 했다. 이번 결과는 그 "일반적으로 tight하지 않음"을 세 가지 구체적 장애로 바꾼다.

- 반대로 tight한 곳에서는 정리 S, C2, 정리 L이 그 이유(층 위 법칙의 존재, 아핀 차원이 꽉 참)를 준다.
