## V02

- **M(p,q)** = p^2/3 + 2pq + q^2 = (p^2 + 6pq + 3q^2)/3
- **쌍대 다항식** f(a,b) = a^2/6 + ab/3 - a/6 + b^2/6 - b/6
- **목격점**: (1/4, 1/2)에서 21개 이차식 중 유일한 최소
- **tight 상태** T = {(0,0), (0,1), (0,3), (1,0), (1,2), (2,1)} (|T| = 6, 기저 1개)
- **영역** {(p,q) ∈ D : M = 이 식} 은 다음 부등식들로 주어진다(D에서 자동 성립하는 facet 제외):

  - q <= 1 - p    (facet h = [0, 0, 2, 0, -1, -1])
  - q <= 2/3 - p/3    (facet h = [0, 2, 0, -1, 0, -1])
  - 2p^2 + 12pq - 6p + 6q^2 - 9q + 3 >= 0    (facet h = [3, -3, -3, 1, 1, 2])

- **달성분포** (영역 전체에서 유효):

  - π(0, 0) = (2p^2 + 12pq - 6p + 6q^2 - 9q + 3)/3
  - π(0, 1) = -3q(p + q - 1)
  - π(0, 3) = (p^2 - 3pq + 3q^2)/3
  - π(1, 0) = -p(p + 3q - 2)
  - π(1, 2) = -p(p - 3q)
  - π(2, 1) = p^2
