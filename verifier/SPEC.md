# 검증기 명세 (point 모드, 형식 `pw5-point/v1`)

이 문서는 `verifier/verify.py`보다 먼저 작성되었고, 검증기는 이 문서만을 근거로 구현한다.
검증기는 최적화 코드(`src/pwbound`)를 import하지 않으며, Python 표준 라이브러리만 쓴다.

> 상태: AI 작성, **사람 검토 완료** (저장소 소유자, 2026-10-29).

## 1. 무엇을 증명하는가

증서는 고정된 (p, q)에 대해 다음 세 가지를 담는다.

1. 32상태 분포 μ (하한 증거)
2. 32상태 쌍대 계수 (u0, u_i, u_ij) (상한 증거)
3. 주장값 V

검증기가 아래 검사를 모두 통과시키면 다음이 성립한다.

- μ는 실행 가능하다. 따라서 M(p,q) ≥ P_μ(S≥3) = V이다.
- 모든 x∈{0,1}^5에서 g(x) = u0 + Σ u_i x_i + Σ_{i<j} u_ij x_i x_j ≥ 1[|x|≥3]이다. 이때 임의의 실행 가능 분포 ν에 대해 다음이 성립한다(약쌍대성).
  - P_ν(S≥3) ≤ E_ν[g(X)] = u0 + Σ u_i p_i + Σ u_ij p_i p_j = V
  - 둘째 등호는 실행 가능성에서 E[X_i]=p_i, E[X_iX_j]=p_ip_j이기 때문이다.
  - 따라서 M(p,q) ≤ V이다.
- 그러므로 **M(p,q) = V이고 μ는 최대화 분포다.** 이 결론은 축소(12상태) 보조정리에 의존하지 않는다.

증서에 담긴 12상태 부분(`reduced`)은 축소 모형 자체의 증서로 따로 검사한다(§4.4). 그리고 32상태 부분과의 정합성을 검사한다(§4.5).

## 2. 고정된 문제 정의

- 변수 X1..X5. 그룹 G1 = {1,2}, G2 = {3,4,5}.
- 목표 주변확률: p_1=p_2=p, p_3=p_4=p_5=q.
- 쌍 10개: (i,j), 1≤i<j≤5.
- 목적 사건: S = X1+…+X5 ≥ 3 (threshold = 3).
- 32상태 키: 길이 5의 `0`/`1` 문자열. **왼쪽 첫 글자가 X1**이다.
- 12상태 키: `"a,b"` (a∈{0,1,2}, b∈{0,1,2,3}). a = X1+X2, b = X3+X4+X5.

## 3. 입력 형식

### 3.1 JSON 파싱 규칙
- JSON의 부동소수점 숫자, `NaN`, `Infinity`는 거부한다.
- 중복 키는 거부한다(어느 깊이든).
- 정수 리터럴은 `problem.groups`와 `problem.threshold`에서만 허용한다.
- 모든 유리수는 문자열이며 정규식 `^-?[0-9]+(/[1-9][0-9]*)?$`(ASCII 숫자만)를 만족해야 한다.
  - 따라서 `"0.4"`, `"1e-3"`, `"nan"`, `"1_000"`, `" 1/2"`는 모두 거부된다.
  - 분모가 0인 값과 `"1/0"`도 거부된다.

### 3.2 최상위 구조 (키 집합이 정확히 일치해야 함)

```json
{
  "format": "pw5-point/v1",
  "problem": {"p": "2/5", "q": "3/5", "groups": [[1,2],[3,4,5]], "threshold": 3},
  "claim": {"value": "61/75"},
  "primal": {
    "reduced": {"0,0": "...", ... 12개},
    "lifted":  {"00000": "...", ... 32개}
  },
  "dual": {
    "reduced": {"y0": "...", "y1": "...", "y2": "...", "y3": "...", "y4": "...", "y5": "..."},
    "lifted": {
      "const": "...",
      "x":  {"1": "...", ..., "5": "..."},
      "xx": {"1,2": "...", "1,3": "...", ... 10개, i<j}
    }
  },
  "provenance": { ... 자유 형식, 검증하지 않음 ... }
}
```

- `provenance`는 사람을 위한 기록이다. 검증기는 이를 읽지 않고 신뢰하지도 않는다.
- 기저(basis) 정보가 들어 있어도 쓰지 않는다.
- 키가 빠지거나 남으면 형식 오류다.

## 4. 검사 항목과 코드

각 검사는 `PASS`/`FAIL`과 코드, 실패 시 상세(어느 상태·어느 쌍인지)를 출력한다.

### 4.1 형식 (실패 시 이후 검사를 하지 않음, 종료 코드 2)
| 코드 | 내용 |
|---|---|
| `E_JSON` | JSON 파싱 실패, float/NaN/Infinity, 중복 키 |

| `E_RATIONAL` | 유리수 문자열 규칙 위반 |
| `E_PROBLEM` | `groups ≠ [[1,2],[3,4,5]]` 또는 `threshold ≠ 3` |

### 4.2 영역
| 코드 | 내용 |
|---|---|
| `E_RANGE` | p 또는 q가 [0,1] 밖 (형식 오류로 취급, 종료 코드 2) |
| `SCOPE` | 0 ≤ p ≤ q ≤ 1. `--allow-outside-scope`가 있으면 p>q도 허용(비대칭 비교용) |

### 4.3 32상태 원·쌍대 (핵심)
| 코드 | 내용 |
|---|---|
| `P_NONNEG` | 모든 μ(x) ≥ 0 |
| `P_TOTAL` | Σ μ(x) = 1 |
| `P_MARGINAL_i` (i=1..5) | Σ_{x_i=1} μ(x) = p_i |
| `P_PAIR_i_j` (10개) | 네 칸 (s,t)∈{0,1}² 모두 P(X_i=s, X_j=t) = P*(X_i=s)·P*(X_j=t). P*는 **목표** 주변확률 p_i이다 |
| `P_OBJECTIVE` | Σ_{|x|≥3} μ(x) = claim.value |
| `D_DOMINATE` | 32개 x 모두 g(x) ≥ 1[|x|≥3]. 실패 시 위반 상태와 g(x) 출력 |
| `D_VALUE` | u0 + Σ u_i p_i + Σ u_ij p_i p_j = claim.value |

### 4.4 12상태 원·쌍대 (축소 모형 증서)
| 코드 | 내용 |
|---|---|
| `R_NONNEG` | 모든 π(a,b) ≥ 0 |
| `R_MOMENTS` | Σπ=1, E[A]=2p, E[B]=3q, E[A(A−1)]=2p², E[B(B−1)]=6q², E[AB]=6pq |
| `R_OBJECTIVE` | Σ_{a+b≥3} π(a,b) = claim.value |
| `R_DOMINATE` | 12점 모두 f(a,b)=y0+y1·a+y2·b+y3·a(a−1)+y4·b(b−1)+y5·ab ≥ 1[a+b≥3] |
| `R_VALUE` | y0+2p·y1+3q·y2+2p²·y3+6q²·y4+6pq·y5 = claim.value |

### 4.5 정합성 (12상태 ↔ 32상태)
| 코드 | 내용 |
|---|---|
| `C_PROJECT` | 각 (a,b)에서 Σ_{x: x1+x2=a, x3+x4+x5=b} μ(x) = π(a,b) |
| `C_DUAL_LIFT` | `dual.lifted`가 `dual.reduced`의 복원과 같다. const=y0. x_1=x_2=y1. x_3=x_4=x_5=y2. xx_{1,2}=**2·y3**. xx_{3,4}=xx_{3,5}=xx_{4,5}=**2·y4**. 교차 6쌍은 xx=**y5** |

`C_DUAL_LIFT`의 근거: x_i² = x_i이므로 다음이 성립한다.
- a(a−1) = 2·x1x2
- b(b−1) = 2·(x3x4+x3x5+x4x5)
- ab = Σ_{i∈G1, j∈G2} x_i x_j

## 5. 출력과 종료 코드
- 표준출력: 검사마다 한 줄씩 `PASS <코드>` 또는 `FAIL <코드>: <상세>`를 쓴다. 마지막 줄은 `VERDICT: PASS` 또는 `VERDICT: FAIL`이다.
- `--json`: 같은 내용을 JSON으로 출력한다(`{"verdict":..., "checks":[{"code":..., "ok":..., "detail":...}]}`).
- 종료 코드: 0 = 모든 검사 PASS, 1 = 하나 이상 FAIL, 2 = 형식·파싱 오류(§4.1, `E_RANGE`).
- 판정: §4.2(`SCOPE`)–§4.5의 모든 검사가 PASS일 때만 `VERDICT: PASS`다.

## 8. region 모드 (형식 `pw5-region/v1`)

> 상태: AI 작성, **사람 검토 완료** (저장소 소유자, 2026-10-29). 검증기는 `format` 값으로 point/region 모드를 고른다.

### 8.1 무엇을 증명하는가

표기는 다음과 같다.
- 12상태 제약행렬 A (6×12). 열은 r(a,b) = (1, a, b, a(a−1), b(b−1), ab)이다.
- 우변 b(p,q) = (1, 2p, 3q, 2p², 6q², 6pq).
- 목적 c(a,b) = 1[a+b≥3].
- 쌍대 실행가능 집합 𝒟 = {y : f_y(a,b) = y·r(a,b) ≥ c(a,b), 12점 모두}.
- 각 y에 대해 Q_y(p,q) = y·b(p,q).
- 영역 D = {0 ≤ p ≤ q ≤ 1}. 꼭짓점은 (0,0), (0,1), (1,1)이다.

검증기가 아래 검사를 모두 통과시키면, 다음 표준 LP 사실과 함께 정리 A·B가 성립한다.

**표준 LP 사실:**
- 강쌍대성
- pointed 다면체 위의 선형함수 최솟값은 꼭짓점에서 달성된다
- 꼭짓점은 선형독립인 tight 제약 6개로 결정된다
- 상보여유성
- 완전 차원 다면 원뿔은 facet 반공간들의 교집합이다

**정리 A (유한 포락선).** [0,1]² 전체에서 M(p,q) = min_{y∈V} Q_y(p,q)이다. 여기서 V는 증서에 나열된 쌍대 꼭짓점 전체다.
- 근거 1: rank A = 6이므로 𝒟는 pointed다.
- 근거 2: 곱분포가 항상 실행 가능하므로 원문제가 실행 가능하고, 목적이 ≤1이므로 유계다.
- 근거 3: V는 𝒟의 꼭짓점 전부다. 검증기는 924개 열 부분집합을 스스로 열거해 이를 확인한다.

**정리 B (조각 분류).** 영역의 내부 int D = {0 < p < q < 1}에서 다음이 성립한다.
- (i) 내부 활성: `active`에 나열된 꼭짓점 y마다, {(p,q) ∈ D : M = Q_y}가 내부점을 가진다. 근거는 목격점이다. 목격점에서 Q_y가 다른 모든 Q보다 strict하게 작으므로, 연속성에 따라 그 근방에서도 그렇다.
- (ii) 비활성: `inactive`에 나열된 꼭짓점은 D 어디에서도 strict 최소가 아니다. 근거는 덮개 트리다.
  - 서로 다른 이차식이 같아지는 집합은 내부가 없다.
  - 따라서 이런 꼭짓점의 영역 {M = Q_y}는 D 안에서 내부가 없다(경계에서만 활성일 수 있다).
- (iii) 영역 기술: 각 활성 꼭짓점 y에 대해 다음이 성립한다. T_y = {s : f_y(s) = c(s)}이다.

  {(p,q) ∈ [0,1]² : M = Q_y} = {(p,q) : b(p,q) ∈ cone{r(s) : s∈T_y}} = {(p,q) : h·b(p,q) ≥ 0, ∀ facet h}
  - 첫 등호는 상보여유성에서 나온다.
  - 둘째 등호는 완전 차원 원뿔의 facet 표현이다. 원뿔이 완전 차원인 것은 r(T_y)의 rank가 6이기 때문이다.
- (iv) 달성분포: `maximizers`의 기저 B마다 x_B(p,q)는 (p,q)의 다항식이다. 다음 두 항등식이 성립하므로 x_B(p,q) ≥ 0인 모든 점에서 x_B는 최대화 분포다.
  - A·x_B(p,q) ≡ b(p,q)
  - Σ_{s∈B} c(s)·x_{B,s}(p,q) ≡ Q_y(p,q)

### 8.2 입력 형식

- 숫자 규칙과 JSON 파싱 규칙은 §3.1과 같다.
- 다항식은 `{"i,j": "<유리수>"}` 꼴이다. p^i q^j의 계수이고, i,j는 0..2 정수이며 i+j ≤ 2다.
- 상태는 `"a,b"`로 쓴다.

```json
{
  "format": "pw5-region/v1",
  "domain": [["0","0"],["0","1"],["1","1"]],
  "dual_vertices": [{"id": "V01", "y": ["y0","y1","y2","y3","y4","y5"]}, ...],
  "active":   [{"id": "V02", "witness": ["1/4","1/2"]}, ...],
  "inactive": [{"id": "V01", "cover": <트리>}, ...],
  "regions":  [{"id": "V02", "tight_states": ["0,0", ...],
                "facets": [[h0,h1,h2,h3,h4,h5], ...],
                "redundant_in_domain": [0, 3, ...]}, ...],
  "maximizers": [{"id": "V02", "basis": ["0,0", ...6개],
                  "x": [<다항식>, ...6개, basis 순서]}, ...],
  "provenance": { ... 검증하지 않음 ... }
}
```

- `domain`은 정확히 [["0","0"],["0","1"],["1","1"]]이어야 한다.
- `facets`의 원소는 JSON 정수다(원시 정수 벡터). 이 필드에서만 정수 리터럴을 허용한다.
- `redundant_in_domain`도 정수 인덱스이고, 같은 예외를 적용한다.
- 덮개 트리는 다음 둘 중 하나다.
  - `{"dominator": "<id>"}`
  - `{"split": [t1,t2,t3,t4]}`: 삼각형 (a,b,c)를 중점 ab, bc, ca로 나눈 (a,ab,ca), (ab,b,bc), (ca,bc,c), (ab,bc,ca)에 순서대로 대응한다. 검증기가 자식 삼각형을 스스로 계산한다.
  - 루트 삼각형은 `domain`이다.

### 8.3 검사 항목

| 코드 | 내용 |
|---|---|
| `RG_RANK` | 검증기가 만든 A의 rank = 6 |
| `RG_FEASIBLE` | 곱분포 Bin(2,p)×Bin(3,q)의 (A,B) 법칙 π(a,b) = C(2,a)p^a(1−p)^{2−a}·C(3,b)q^b(1−q)^{3−b}가 A·π ≡ b(p,q)를 **다항식 항등식으로** 만족 |
| `RG_VERTICES` | 검증기가 C(12,6)=924개 부분집합을 열거해 얻은 쌍대 실행가능 기저해 y의 집합 = 증서의 `dual_vertices` y 집합. id는 서로 달라야 함 |
| `RG_PARTITION` | `active`와 `inactive`의 id가 서로소이고 합집합이 전체 id |
| `RG_ACTIVE_<id>` | 목격점이 0 < p < q < 1이고 Q_id(목격점) < Q_j(목격점), 모든 j ≠ id |
| `RG_INACTIVE_<id>` | 덮개 트리의 모든 잎에서 지배자 j ≠ id이고, 잎 삼각형 위에서 min(Q_id − Q_j) ≥ 0 (정확 계산, §8.4) |
| `RG_REGION_LIST` | `regions`의 id 목록 = `active`의 id 목록 (각각 정확히 한 번) |
| `RG_REGION_<id>` | 다음을 모두 만족해야 한다. ① tight_states = 검증기가 계산한 T_id. ② r(T_id)의 rank = 6. ③ facets = 검증기가 계산한 facet 집합(아래). ④ redundant_in_domain의 각 h에 대해 h·b(p,q) ≥ 0이 D 전체에서 성립(§8.4) |
| `RG_MAXIMIZER_<id>_<n>` | basis ⊆ T_id이고 6개가 서로 다르며 r(basis)가 정칙, A·x ≡ b(p,q), Σ c(s)x_s ≡ Q_id. \|T_id\|=6이면 추가로 x의 각 성분이 서로 다른 facet 다항식 h·b(p,q)의 양의 스칼라배 |

- **facet 계산.** r(T_id) 중 5개를 고른 모든 부분집합에서 rank가 5이면 그 1차원 영공간 벡터 h를 구한다. 모든 r(s), s∈T_id에 대해 h·r(s)의 부호가 한쪽(≥0 또는 ≤0)이면, 부호를 맞추고 원시 정수 벡터로 정규화해 facet으로 채택한다.

### 8.4 삼각형 위 이차식의 정확한 최솟값

f(p,q) = a p² + b q² + c pq + d p + e q + k의 닫힌 삼각형 위 최솟값은 다음 후보점들에서의 최솟값이다.
1. 세 꼭짓점
2. 각 변을 t∈[0,1]로 매개화한 이차식 αt²+βt+γ에서 α>0이고 0<t*=−β/(2α)<1인 점
3. 4ab−c²>0이고 a>0일 때, 기울기 0의 점이 삼각형 안(경계 포함)에 있으면 그 점

모든 계산은 Fraction으로 한다.
